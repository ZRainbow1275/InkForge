Scope:

- Slice: Zhihu preview-fidelity fallback for InkForge inline SVG modules.
- Goal contribution: strengthen AC6's Zhihu SVG-as-img evidence without claiming
  public image hosting, upload, credentialed sync, or publish success.

## Change

`renderZhihuMockHtml()` now converts InkForge inline SVG modules into image fallback before
the Zhihu preview HTML is returned.

Input shape:

```html
<section data-ink-svg="divider-grid">
  <svg viewBox="0 0 1080 60" width="100%">...</svg>
</section>
```

Preview output shape:

```html
<img
  data-ink-svg="divider-grid"
  src="data:image/svg+xml;charset=utf-8,..."
  alt="InkForge divider-grid image fallback"
  style="width:100%;height:auto;display:block;"
>
```

The preview therefore stays visual, but it no longer implies that Zhihu accepts inline SVG
in the publishable Markdown path.

## Contract

- WeChat preview/export may keep safe inline SVG.
- Zhihu preview must show InkForge SVG motifs as image fallback.
- Zhihu final Markdown must still block local, `blob:`, `data:`, localhost/private,
  temporary preview, or WeChat-CDN image URLs until a public HTTPS/platform-host upload
  path exists with alt/caption semantics.
- This slice does not claim Zhihu upload, public host rewrite, credentialed sync, or publish.
