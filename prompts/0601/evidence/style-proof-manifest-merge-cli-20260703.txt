Style Proof Manifest Merge CLI - 2026-07-03

Scope:
- Local merge validation for multiple redacted StyleProofManifest JSON packs.
- No browser automation, no phone preview, no sync, no upload, no schedule, no publish.

Implemented:
- pnpm -C inkforge style-proof:manifest-merge --file <redacted-manifest.json> [--file <...>]
- Optional --out <merged-pack.json> with --force overwrite opt-in.

Behavior:
- Reads each input file with getStyleProofManifestJsonIntakeReport().
- Merges accepted manifest rows in memory.
- Revalidates the merged { manifests: [...] } pack with getStyleProofManifestIntakeReport().
- Prints sanitized text or JSON summaries only.
- Blocks --out when source schema errors, rejected rows, schema warnings, merged schema errors,
  merged schema warnings, semantic issues, empty packs, or existing output files are present.
- Does not print input paths, output paths, raw artifact references, browser profile paths,
  cookies, tokens, HAR references, QR payloads, account screenshots, draft URLs, or publish URLs.

Exit codes:
- 0: merged pack is schema-clean and semantic-clean; --out write succeeded if requested.
- 1: JSON parsed, but merge/write is blocked by schema, warning, semantic, hygiene, empty-pack,
  or output-exists issues.
- 2: CLI usage, unreadable input file, or write failure.

Regression coverage:
- Clean multi-file text merge.
- JSON output shape and sensitive-fragment hygiene.
- Optional --out writes only a clean merged pack.
- Existing output path blocks unless --force is supplied.
- Sensitive artifact references block merge output before writing.
- Malformed JSON returns a sanitized merge-blocked report.
- Missing --file, conflicting output modes, unknown arguments, and unreadable files exit 2.
