# 小红书渲染规则手册

> 基于 2025-2026 年全网调研整理，参考 Reditor、uplog、xiaohongshu-text-layout 等工具实践验证

---

## 一、平台内容限制

### 文字规则
| 维度 | 限制 | 建议 |
|------|------|------|
| 单篇字数 | 最多 1000 字（含标点、空格） | 600-800 字最佳 |
| 标题字数 | 最多 20 字 | 带关键词 + emoji，10-15 字最吸睛 |
| 段落行数 | 无硬限制 | 每段 ≤ 5 行，段间空行 |
| 话题标签 | 最多 10 个 | 3-5 个精准标签 |

### 图片规则
| 维度 | 限制 | 建议 |
|------|------|------|
| 比例 | 仅支持 1:1 和 3:4 | 3:4 竖版最佳 |
| 推荐分辨率 | — | 1080×1440px 或 1242×1660px |
| 图片数量 | 最多 18 张 | 6-9 张适中 |
| 封面 | 第一张图为封面 | 核心内容居中，避免裁剪 |

### 格式支持（**极其有限**）
| 元素 | 支持度 | 说明 |
|------|--------|------|
| 纯文本 | ✅ | 基础文字内容 |
| 换行/空行 | ✅ | 段落分隔 |
| Emoji | ✅ | 原生支持，推荐使用 |
| 加粗 | ❌ | 不支持 Markdown 加粗 |
| 斜体 | ❌ | 不支持 |
| 标题格式 | ❌ | 无 H1-H6 概念 |
| 超链接 | ❌ | 不支持点击跳转 |
| 表格 | ❌ | 完全不支持 |
| 代码块 | ❌ | 不支持代码格式 |
| HTML/CSS | ❌ | 纯文本平台 |
| 列表符号 | ❌ | 无原生列表，需 emoji 替代 |
| 图片内嵌 | ❌ | 图片单独上传，不嵌入文字中 |

## 二、排版最佳实践

### 1. 标题优化
```
❌ 错误: 关于微信公众号Markdown编辑器的最佳实践总结与分析报告
✅ 正确: 🔥 公众号排版神器 | 5分钟搞定高颜值文章
```
- 限制 20 字以内
- 首字带 emoji 吸引眼球
- 使用「|」「/」分隔关键信息
- 包含数字（提升点击率）

### 2. 段落控制
```
❌ 错误（密集文字墙）:
这是一段很长的文字，没有分段，读起来非常累，用户看到就想划走，因为小红书是一个视觉驱动的平台，密集文字会严重影响阅读体验和互动率。

✅ 正确（短段落 + 空行）:
这是一段很长的文字 📝

没有分段就读起来非常累

用户看到就想划走 😅

因为小红书是视觉驱动平台
短段落 = 好体验 ✨
```
- 每段 ≤ 5 行
- 段间用空行分隔
- 关键信息单独成段

### 3. Emoji 使用规范
```
密度建议: 1-2 个 emoji / 100 字

标题: 必须带 emoji（开头或结尾）
段落首: 推荐带 emoji 标记段落主题
段落尾: 可选 emoji 收尾
序号: 使用 emoji 替代数字列表
分隔: 使用 emoji 分隔线

常用序号 emoji:
1️⃣ 2️⃣ 3️⃣ 4️⃣ 5️⃣ 6️⃣ 7️⃣ 8️⃣ 9️⃣ 🔟

常用分隔线:
━━━━━━━━━━━━━━
✦ ✦ ✦ ✦ ✦
· · · · · · · · ·
▪️▪️▪️▪️▪️▪️▪️▪️

常用标记 emoji:
📌 重点  💡 技巧  ⚠️ 注意  ✅ 推荐
❌ 避免  🔥 热门  💰 省钱  🎯 目标
📝 笔记  🌟 亮点  👉 操作  ⏰ 时间
```

### 4. 列表替代方案
```
Markdown 列表:
- 项目一
- 项目二
- 项目三

小红书替代:
1️⃣ 项目一
2️⃣ 项目二
3️⃣ 项目三

或:
✅ 项目一
✅ 项目二
✅ 项目三

或:
📌 项目一
📌 项目二
📌 项目三
```

### 5. 表格替代方案
```
Markdown 表格:
| 工具 | 价格 | 评分 |
|------|------|------|
| A    | 免费 | ⭐⭐⭐ |
| B    | ¥99  | ⭐⭐⭐⭐ |

小红书替代:
📊 工具对比

1️⃣ 工具A
💰 价格：免费
⭐ 评分：3星

2️⃣ 工具B
💰 价格：¥99
⭐ 评分：4星
```

### 6. 代码块替代方案
```
Markdown 代码块:
```javascript
const hello = "world"
```

小红书替代:
💻 代码片段:
———————————
const hello = "world"
———————————
（建议用截图替代）
```

### 7. 链接替代方案
```
Markdown 链接:
[点击查看](https://example.com)

小红书替代:
👉 搜索关键词「xxx」即可找到
或
🔗 链接见评论区置顶
```

## 三、Markdown → 小红书转换策略

### 转换规则映射表

| Markdown 元素 | 转换策略 | 输出格式 |
|--------------|---------|---------|
| `# 标题` | emoji + 大写/加强文字 | `🔥 标题文字` |
| `## 二级标题` | emoji + 文字 | `📌 标题文字` |
| `**加粗**` | 保留文字，去除标记 | 纯文字 |
| `*斜体*` | 保留文字，去除标记 | 纯文字 |
| `- 列表项` | emoji 序号替代 | `✅ 列表项` |
| `1. 有序列表` | emoji 数字替代 | `1️⃣ 列表项` |
| `> 引用` | emoji 标记 | `💬 引用内容` |
| `[链接](url)` | 文字 + 搜索提示 | `文字（搜索关键词xxx）` |
| `![图片](url)` | 图片提示 | `📷 见图片X` |
| `` `行内代码` `` | 保留文字 | 纯文字 |
| ```` ```代码块``` ```` | 截图提示或文字引用 | `💻 代码见图片X` |
| `| 表格 |` | 列表化描述 | emoji + 逐项列出 |
| `---` | emoji 分隔线 | `━━━━━━━━━━` |
| `$公式$` | 文字描述 | 公式文字描述 |
| `~~删除线~~` | 保留文字 | 纯文字 |

### 后处理步骤
```
1. HTML/Markdown 标记清理 → 纯文本
2. 标题 → emoji + 文本
3. 列表 → emoji 序号
4. 表格 → 列表化
5. 链接 → 文字 + 搜索提示
6. 代码块 → 截图提示
7. 段落分割（≤5 行/段）
8. Emoji 密度检测与补充
9. 字数统计（≤1000 字检查）
10. 生成话题标签建议
```

## 四、质量检测清单

### 发布前自动检测
| 检测项 | 规则 | 严重度 |
|--------|------|--------|
| 字数超限 | > 1000 字 | ❌ 阻断 |
| 标题超长 | > 20 字 | ⚠️ 警告 |
| 段落过长 | > 5 行/段 | ⚠️ 警告 |
| Emoji 过少 | < 1个/200字 | 💡 建议 |
| Emoji 过多 | > 3个/100字 | 💡 建议 |
| 含 HTML 标签 | 任何 HTML | ❌ 阻断 |
| 含超链接 | http(s)://... | ⚠️ 警告（转搜索提示） |
| 含 Markdown 标记 | `**`, `##`, ``` | ⚠️ 警告（未被正确转换） |
| 图片比例 | 非 3:4 或 1:1 | 💡 建议 |
