# 设计稿逐屏视觉对齐与原生验收

## Goal

以 `.trellis/tasks/07-29-rendering-visual-system-reconstruction/research/concept-boards/`
中的七张最终方向板为权威视觉基准，把 InkForge 当前“只换色、加边框”的微信文章渲染，
修正为七套在报头、标题、正文节奏、语义组件、图像装裱和文末署名上均可立即辨认的
出版级版式，并在真实 Tauri/WebView2 软件中完成逐屏视觉验收。

本任务的完成标准不是“HTML 非空”或“测试通过”，而是用户在原生软件中打开任意一套
风格时，能够直接看出它继承了对应设计稿的构图语言，同时仍可安全复制到微信公众号。

## Background and Confirmed Facts

1. 权威需求源为 `SystemPrompt/System Prompt.md`：
   - 总体风格应简洁、现代、高级、大气，融合 Markdown、数字构成主义、先锋主义、
     社会主义现实主义与人文出版气质；
   - 内容第一、阅读第一，手机端 14px 基准下每行至少约 22 个中文字符；
   - 十类文章由七个 VisualVariant 覆盖，不维护十套或二十一套独立 renderer；
   - 每类文章不仅颜色不同，构图、节奏、信息组织和组件语言也必须不同。
2. 七张最终方向板已存在：
   - `v1-critical-translation-final-direction.png`
   - `v2-jurisprudence-atlas-final-direction.png`
   - `v3-industry-section-final-direction.png`
   - `v4-fact-wire-kiln-constructivist-draft2a.png`
     与 `v4-fact-wire-graphite-documentary-draft2c.png`
   - `v5-machine-foundry-final-direction.png`
   - `v6-knowledge-weave-final-direction.png`
   - `v7-human-margins-final-direction.png`
3. 本轮原生 Tauri 目检确认当前预览与方向板显著不一致：
   - 通用“墨铸 · 文章”抬头替代了各 Variant 的专属报头；
   - 普通段落普遍被左轨、底线或色块逐段包裹，正文不再连续，阅读节奏破碎；
   - 七套主要依赖颜色、边框宽度和圆角区分，缺少设计稿中的构图母题；
   - 短文中尤其明显：页面表现为多色边框堆叠，而不是完整出版物；
   - 导出面板把 900px 总宽中的 400px 固定给控制区，预览缺少稳定的微信设备画布，
     难以进行设计稿对照。
4. 当前能力必须保留：
   - 微信 16 个已有 preset ID；
   - 七 Variant / 十 Article Profile 映射；
   - Typography 用户设置；
   - 写作组件、SVG 模块、sanitize、Juice 内联、质量检查和平台转换；
   - 小红书、知乎现有转换能力。
5. 当前轮次只把微信公众号视觉与可复制产物作为完成门槛。小红书、知乎的真实发布由用户
   手动测试，不在本任务自动执行。

## Requirements

### R1. 设计稿为唯一视觉基准

- 七个 Variant 必须分别继承对应最终方向板的：
  - 首屏轮廓与视觉重心；
  - 字体角色和标题比例；
  - 主色、辅色、纸张色与明暗关系；
  - 章节节奏、正文密度和留白；
  - 表格、引文、时间线、数据、图集、来源、名片和链接的轮廓语言；
  - 文末署名、CC 协议和来源系统。
- 不要求复制方向板中的虚构文章、图片、人物、数字或来源。
- 不允许以“微信不支持”为理由退化成裸文本或通用边框模板；必须使用微信安全的
  HTML、inline style 和短图形 SVG 重新表达相同设计意图。

### R2. 七套必须在普通正文中也成立

- 即使文章只有标题和普通段落，每套也必须通过报头、标题、正文节奏、章节路标和纸张处理
  被立即辨认，不能依赖恰好存在的图片、统计卡或时间线。
- 普通正文以连续阅读为主，不得把每个段落都做成卡片、色块或多重边框。
- 设计差异必须来自结构、比例、节奏、字体角色和领域母题，而不只是主色。

### R3. 七套专属视觉签名

- V1 典藏译本：酒红装帧、蓝红双轨、典藏书页、原文/译文/译注/版本谱系语言。
- V2 法理坐标：深蓝法理地图、坐标和 IRAC 轴、权威层级、连续法学正文。
- V3 产业剖面：石墨与黄铜、奢华研报封面、价值链、情景带、指标和风险披露。
- V4 事实通讯：铸红构成主义与石墨纪实、硬标题、时间码、来源和事实状态。
- V5 数字铸场：石墨工业场、Kiln 热端、Mono 技术角色、材料—模具—淬炼—锻次轨。
- V6 知识经纬：铜绿知识网络、问题—概念—证据—应用—复盘、回链和页边注。
- V7 人文边页：
  - `playful` 为成熟编辑拼贴、对话节拍和非规则装裱；
  - `quiet` 为纪实信笺、慢正文、时间线和诗性引文；
  - 两档共享品牌纪律，但不能只靠颜色切换。

### R4. 真实数据与无内容降级

- 标题、作者、分类、歌曲、图片、数字、来源、日期、单位和平台信息只能来自真实文章或用户输入。
- 缺少数据时省略对应模块并保持构图完整，不生成示例数字、假作者、假 DOI、假图片或假来源。
- 文章标题必须进入真实渲染上下文；不能只在文件名或下载记录中使用。
- 现有时间线、对比卡、统计卡、图集、引文来源、歌曲、名片、文章链接和微信媒体组件继续
  使用已验证的数据模型。

### R5. 微信阅读与兼容性

- 390px 等效内容宽度、14px 正文基准下，每行至少约 22 个中文字符。
- H1–H6、段落、strong、em、del、列表、链接、引用、表格、代码、数学公式、Mermaid、
  图片、图注、脚注、来源和全部写作组件必须有完整视觉处理。
- 微信导出不得依赖伪元素、脚本、事件、外部 CSS、CSS 变量、渐变、滤镜、mask、
  长文本 SVG、定位式正文、flex/grid 正文布局。
- 预览与最终复制产物共享同一设计意图；预览不能美化而复制后退化。

### R6. 原生软件中的可视化选择与预览

- 导出面板必须提供稳定的微信设备画布，完整显示首屏，不再让控制区挤压视觉判断。
- 16 个微信 preset 继续可选，并明确映射到七个视觉人格。
- 选中风格后应立即更新预览，滚动位置与交互保持稳定。
- 诊断、证据和高级参数仍可访问，但不得压过“风格选择 + 真实预览”的主任务。
- 全程使用真实 `InkForge.exe` / Tauri WebView2 验收，不用浏览器截图冒充软件验收。

### R7. 不破坏现有功能

- 不删除任何已有功能、preset、组件、模块或设置。
- 不新增第二套 renderer、开放式模板 DSL、主题市场或新状态仓库。
- 不改写文章正文，不迁移用户数据，不把方向板素材打包进运行时。
- 小红书和知乎必须通过现有回归测试，但不要求本任务完成平台发布。

## Acceptance Criteria

- [ ] AC-1：七个 Variant 的原生微信首屏与对应方向板在构图轮廓、标题层级、色彩关系和
  领域母题上可直接对应，不再表现为同一模板换色。
- [ ] AC-2：七套普通正文均为连续出版阅读流；不存在“每个普通段落都是卡片/边框块”的通病。
- [ ] AC-3：七套在不含图片和高级组件的真实短文中仍可辨认；缺失内容不生成假数据。
- [ ] AC-4：至少使用一篇真实长文验证 H1–H6、段落、引用、列表、表格、代码、公式、图片、
  图注、来源、CC 和已存在写作组件的中段及文末构图。
- [ ] AC-5：V1–V7 分别具备 R3 所列专属签名；V7 playful/quiet 两档均验收。
- [ ] AC-6：文章真实标题、分类、阅读时间和字数进入抬头/封面；缺失字段被省略而非占位。
- [ ] AC-7：390px 等效画布的 14px 正文达到约 22 个中文字符/行，无大面积无意义边距、
  横向裁切、重叠或异常缩进。
- [ ] AC-8：导出面板在 1400×900 原生窗口中完整展示控制区与微信设备预览，首屏可用于视觉判断。
- [ ] AC-9：16 个微信 preset 全部可选、即时预览且映射稳定；用户 Typography 设置仍真实生效。
- [ ] AC-10：时间线、对比、统计、图集、引文、歌曲、名片、文章链接和微信媒体组件在七套中
  均有主题化样式或诚实 fallback。
- [ ] AC-11：复制后的微信 HTML 通过安全检查，语义内容完整，未引入方向板假数据、
  市场编辑器残留、远程信标或不支持 CSS。
- [ ] AC-12：目标 Vitest、export 全量测试、ESLint、`vue-tsc`、生产构建和
  `style-proof:application-preflight` 全部通过。
- [ ] AC-13：真实 Tauri 软件生成七套首屏、中段、文末视觉矩阵并由本会话逐张目检；
  临时证据不得包含账号、Cookie、Token、浏览器 Profile 或未脱敏文章内容。
- [ ] AC-14：小红书、知乎转换回归不被破坏；其平台发布仍明确交由用户手测。

## Out of Scope

- 自动登录、发布或同步微信公众号、小红书、知乎。
- 微信手机预览、深色模式、封面缩略图、定时发送和正式发布成功证明。
- 首页、设置、同步、悬浮面板、检查器和编辑器其他视觉债。
- 从 135、秀米或概念板复制 DOM、图片、CSS、账号数据或版权素材。
- 新增远程主题市场、插件协议、通用页面 DSL 或第二套渲染架构。

## Open Questions

无阻塞问题。仓库中的最终方向板、原始 System Prompt 和用户本轮“与设计稿完全不一样”
的反馈已经共同确定视觉基准；细节按“方向板构图意图优先、微信安全约束内重建”的原则执行。
