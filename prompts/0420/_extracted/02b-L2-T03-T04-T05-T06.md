## Task 03 — 键盘快捷键 / FindReplace / 输入法兼容

### 核心决策摘要（3-5 条）

1. **FindReplace 选最强能力方案（C）**：正则 + 大小写敏感 + 全词匹配 + 跳转 + 计数，面板落在 VS Code 风格右上角浮窗（A），定位明确。
2. **快捷键热更新 + 冲突警告可覆盖**：修改即时生效（T03-03=A），冲突录制时警告但允许覆盖（T03-04=A），用户自治。
3. **Ctrl+\ 解耦为纯模式切换，清除格式改用 Ctrl+Shift+N**（T03-06=C），消除双重语义的歧义。
4. **快捷键作用域全局统一（T03-09=A）**，但组合键支持深度扩展到可视化序列提示（T03-10=D），照顾高级用户。
5. **浏览器冲突规则未定（T03-11=？）**——用户明确"不做 Web 版，仅 App"，需 Tauri/系统层单独设计一套冲突策略。

## Task 04 — 渲染引擎 / KaTeX / Mermaid / 代码块 / 导出

### 核心决策摘要（3-5 条）

1. **KaTeX 全量 WYSIWYG + 红色报错 UI（T04-01=A, T04-02=A）**：实时渲染 + KaTeX 原生错误提示，错误提示在修改后自动消失（T04-12=A）。
2. **Mermaid 不做内联渲染，使用右侧 Stage 面板（T04-03=C）**：与编辑流程解耦，错误仍展示原生信息（T04-04=A）。
3. **代码高亮主题 GitHub 系 + 加载全部 180 种语言（T04-05=A, T04-07=C）**：接受 ~400KB 体积代价换通用性。
4. **平台渲染一切"以平台规则决定"**：主题跟随全局 + 按平台再适配（T04-11=B），嵌入策略、安全沙箱、代码块契约全部按平台自身规则走（T04-13/14/15）。
5. **导出覆盖面 = 所有平台 + HTML + Markdown + PDF（T04-08=C；选项 D 隐含但选了 C）**——注意：用户选 C 但 C 文案不含 PDF（D 才含 PDF），可能是笔误，归为矛盾项。
