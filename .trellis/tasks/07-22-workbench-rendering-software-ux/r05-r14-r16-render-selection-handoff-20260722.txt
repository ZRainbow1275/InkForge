Scope

Root cause
- Workstation persisted the current platform/preset pair.
- ExportModal initialized per-platform preset state from fixed defaults and did not write selection changes back.
- PublishView initialized WeChat from the legacy theme store, initialized XHS/Zhihu from fixed IDs, and omitted canonical typography/custom CSS from WeChat Publish output.

- WeChat Publish uses typographyToWechatCss with settings.appearance.typography, font family, preset accent, and export custom CSS.
- The Publish first-line-indent switch writes the canonical paragraphIndent field.
- Zhihu hides the Mac-code, line-number, and indent section because its converter does not consume those options.
