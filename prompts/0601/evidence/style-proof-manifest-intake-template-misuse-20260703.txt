Style Proof Manifest Intake Template Misuse Guard - 2026-07-03

Scope:
- Local manifest-intake schema hardening for caller-supplied redacted StyleProofManifest JSON.
- No browser action, no platform upload, no sync, no schedule, no publish, no artifact import.

Problem:
- External handoff and release-preflight commands intentionally output operator guidance objects.
- Those objects can include draft/template-only fields such as draftOnly, templateOnly, notProof,
  artifactTemplate, artifactDraftTemplate, manifestDraftTemplate, operatorWorksheet,
  artifactGuidance, baseFields, acceptedValues, sourceRows, and command helpers.
- If an operator pastes one of those objects into StyleProofManifest.artifacts[], intake must not
  treat it as proof even when the row also contains otherwise valid StyleProofArtifact fields.

Implemented:
- Added a manifest-intake reserved template artifact field set.
- Added schema error style-proof-manifest-intake-template-artifact for artifact rows containing
  draft/template/guidance-only fields.
- Rejected template/guidance rows before they enter accepted manifests or semantic proof
  accounting.
