## 关键决策速览（提炼自第一层 60 题）

- **核心定位**: 个人深度写作 + 多渠道发布（A+D 优先，知识增强 C 近期，团队 B 远期）
- **内容权威源**: Markdown 文本为唯一权威源，但当前过渡期保留 HTML 严格契约
- **编辑范式**: Typora 式默认（B），切换需保持选区/撤销/版本/评论锚点连续
- **同步**: 远期基础设施但 v2.1 必须落地 WebDAV / Git / 自有服务三选一（D 选 Git）
- **多账户**: 本地 Profile 完整隔离 + 跨 profile 不共享（v2.1 不做共享）
- **冗余开发**: C 级（删除/恢复/导入/导出/切账户/批量都需确认或备份），保存/恢复/回滚/导出优先冗余
- **性能 SLO**: 输入零延迟、保存 ≤1s、冲突检测 ≤10s、导出 ≤3min；Lighthouse >80
- **运行环境**: 仅 Tauri（Web 仅供开发调试）
- **视觉一致性**: D 级（任何新组件必须映射到现有设计语汇，禁止"似是而非的新风格"）
