Scope:

135 SVG editor:
- Page: https://www.135editor.com/svgeditor/
- Page title: 在线SVG编辑器_微信公众号SVG互动效果制作-135编辑器.
- A visible free-trial SVG item was clicked. The material-included confirmation was explicitly
  accepted through the primary button.
- The editor canvas reported 16 blocks after the insertion pass. Data-name categories included
  multiselectpopup, carouselslide, slidesectorclickredpacket, clickelementscaleimagesspread, and
  coverclickmovewithspread.
- The active inserted block was data-name=multiselectpopup with a 336 x 575 visible canvas.
- The active block used:
  - block wrapper: margin 0, padding 0, transparent background, position relative.
  - content image layer: background image hosted by the vendor CDN, background-size 100%.
  - zero-flow section: font-size 0, line-height 0, margin 0, padding 0, text-align center.
  - background SVG: viewBox 0 0 1080 1850, display inline-block, width 100%, margin-top -1px,
    overflow hidden, background-repeat no-repeat, background-position center,
    background-size 100.1% 100.1%, pointer-events none, user-select none, vertical-align top.
  - trigger wrapper: absolute full-block edit-trigger overlay.
  - trigger zones: trigger__ajuster overlays with percentage inset values and translucent
    background color. The visual SVG layer stays non-interactive; interaction is modeled by
    normalized overlay zones.
- Existing coverclickmovewithspread blocks also used the same zero-flow section plus background SVG
  pattern with viewBox 0 0 1080 1920 and 100.1% background sizing.

135 reusable rules for InkForge:
- Treat 1080-wide vendor SVG canvases as design-coordinate source material that must be normalized
  into InkForge-owned module geometry.
- Keep image/background visual layers pointer-events:none when interaction is handled by overlay
  trigger zones.
- Preserve the no-gap strategy through zero font/line-height wrappers and the -1px SVG top offset,
  but express it through InkForge module CSS rather than copying vendor wrappers.
- Store trigger zones as normalized percentages. Do not commit vendor data-name strings,
  framework data attributes, account state, or hosted material URLs as proof artifacts.
