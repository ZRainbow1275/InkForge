Scope:
- Add a local helper that turns real raster artifact metadata into `XhsImageArtifactManifest`.
- No Xiaohongshu account upload, platform preview, mobile preview, sync, or publish action is
  executed or claimed.

Implemented:
- `createXhsImageArtifactManifestFromRaster(options)`
- `getDataUrlByteLength(dataUrl)`
- `inferXhsImageArtifactFormat({ mime, fileName, src })`
- `inferXhsImageArtifactRatio(width, height)`

Behavior:
- Data URL path:
  - parses real PNG/JPEG/WebP dimensions through existing `extractFromDataUrl()`;
  - computes byte length from the base64 payload;
  - builds a one-page XHS manifest with cover/body-reference defaults.
- Local file metadata path:
  - accepts explicit width, height, format, bytes, existence, and crop status;
  - infers `3:4` or `1:1` from dimensions when ratio is not provided.
- The helper does not bypass `validateXhsImageArtifactManifest()`.
- Unsupported ratio, unsupported/missing format, missing dimensions, or missing bytes throws instead
  of creating a fake manifest pass.

Regression coverage:
- Computes bytes for the real tiny PNG fixture data URL.
- Infers PNG/JPEG formats and XHS-supported 3:4 / 1:1 ratios.
- Builds a validator-clean manifest from a generated PNG data URL.
- Builds a validator-clean manifest from explicit 1080x1440 local raster metadata.
- Rejects incomplete or unsupported raster metadata.
