## 增强卷新增维度解释

### 为什么需要这些新维度？

| 新维度 | 原问卷缺口 | 不补充的风险 |
|--------|-----------|-------------|
| 文档生命周期 | 原卷只问了版本和保存，没问文档状态 | 文件管理器和 Hub 无法正确组织文档 |
| 文件管理 | 原卷几乎没有涉及 FileManager | 内容组织体验成为短板 |
| 编辑器微交互 | 原卷只问了 Typora 元素行为 | "编辑器手感"无规范，实现方各自为政 |
| 写作辅助 | 原卷只轻触专注/打字机 | 写作工具的核心竞争力被忽视 |
| Workstation 布局 | 原卷没有问四栏布局的灵活性 | 布局过于僵硬，无法适配不同场景 |
| StatusBar/导航 | 原卷完全没有 | 用户对系统状态一无所知 |
| 导出体验 | 原卷只问了渲染一致性 | 导出流程可用但不好用 |
| Markdown 扩展 | 原卷只覆盖 KaTeX/Mermaid | Callout/脚注/TOC 等常见需求无方案 |
| Tauri 桌面端 | 原卷只有 G-06 一题 | 浪费了 Tauri 的桌面端能力 |
| FTUE/引导 | 原卷几乎没有 | 新用户无法上手 |
| 崩溃恢复 | 原卷只轻触 | "冗余开发"要求无法满足 |
| 字体/主题 | 原卷只问了暗色 | 视觉定制深度不够 |
