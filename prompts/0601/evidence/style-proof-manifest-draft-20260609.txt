Runtime contract

- The API returns a redacted StyleProofManifest with artifacts: [].
- If a choiceId is supplied and no scope is supplied, the draft uses scope: style-choice.
- If no choiceId is supplied, the draft uses scope: evidence-label.
- The API may carry a caller-supplied artifactFingerprint, but it does not generate or infer one.
- The caller must fill artifacts only after collecting real, redacted evidence from tests,
  CloakBrowser, a platform editor, phone preview, credentialed sync, or publish inspection.
- getStyleProofManifestReport() is then used to enumerate missing or invalid proof rows.
