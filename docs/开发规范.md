## 二、TypeScript 规范

### 2.1 类型定义

```typescript
// ✅ 推荐：使用 interface 定义对象类型
interface Category {
    id: string
    name: string
    createdAt: Date
}

// ✅ 推荐：使用 type 定义联合类型
type EditorStatus = 'idle' | 'loading' | 'ready' | 'saving' | 'error'

// ✅ 推荐：使用 const as const 定义字面量数组
const FONT_FAMILIES = ['sans', 'serif', 'mono'] as const
type FontFamily = typeof FONT_FAMILIES[number]
```

### 2.2 函数签名

```typescript
// ✅ 推荐：显式返回类型
async function fetchArticles(): Promise<Article[]> { ... }

// ✅ 推荐：可选参数使用默认值
function highlightCode(html: string, lineNumbers = false): string { ... }

// ❌ 避免：any 类型
function process(data: any) { ... }

// ✅ 替代：使用 unknown + 类型守卫
function process(data: unknown): void {
    if (isValidData(data)) { ... }
}
```

### 2.3 错误处理

```typescript
// ✅ 推荐：使用自定义错误类
throw new AppError(ErrorCode.DB_READ_FAILED, '读取分类失败', { categoryId })

// ✅ 推荐：捕获时检查错误类型
try {
    await repository.findAll()
} catch (err) {
    if (err instanceof AppError) {
        notify(err.toUserMessage())
    } else {
        logger.error('未知错误', err)
    }
}
```

## 四、Pinia Store 规范

### 4.1 Store 结构

```typescript
export const useXxxStore = defineStore('xxx', () => {
    // === State ===
    const items = ref<Item[]>([])
    const loading = ref(false)
    const error = ref<string | null>(null)

    // === Getters (computed) ===
    const itemCount = computed(() => items.value.length)
    const hasError = computed(() => error.value !== null)

    // === Actions ===
    async function fetchItems() { ... }
    function addItem(item: Item) { ... }
    function removeItem(id: string) { ... }

    // === Return ===
    return {
        // State
        items,
        loading,
        error,
        // Getters
        itemCount,
        hasError,
        // Actions
        fetchItems,
        addItem,
        removeItem
    }
})
```

## 七、Git 规范

### 7.1 Commit Message

```
<type>(<scope>): <subject>

<body>

<footer>
```

**Type 类型**:
| Type | 说明 |
|------|------|
| `feat` | 新功能 |
| `fix` | Bug 修复 |
| `docs` | 文档更新 |
| `style` | 代码格式（不影响逻辑） |
| `refactor` | 重构 |
| `perf` | 性能优化 |
| `test` | 测试相关 |
| `chore` | 构建/工具变动 |

**示例**:
```
feat(export): 添加小红书导出格式

- 实现 3:4 图片裁剪
- 添加 emoji 智能插入
- 简化文本格式

Closes #123
```

### 7.2 分支命名

| 分支类型 | 命名规范 | 示例 |
|---------|---------|------|
| 功能 | `feature/xxx` | `feature/xhs-export` |
| 修复 | `fix/xxx` | `fix/css-inline-bug` |
| 重构 | `refactor/xxx` | `refactor/editor-fsm` |
| 文档 | `docs/xxx` | `docs/api-reference` |
