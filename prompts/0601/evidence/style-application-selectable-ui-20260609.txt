## Runtime Decision

This slice splits market style state into two separate gates:

- `available`: the style family is allowed by the runtime catalog for the platform and
  current evidence labels.
- `selectable`: the available style also maps to a real existing InkForge renderer path,
  preset, export option, manifest, or fallback that the current UI can actually create.

The UI must never imply that a style can be applied when the renderer would ignore it. A
style card is clickable only when both gates pass. Clicking a selectable style uses the same
existing preset-selection path as the preset grid so the real preview and export artifact
are regenerated by the existing pipeline.
