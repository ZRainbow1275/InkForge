Zhihu Image Manifest Builder - 2026-06-19

Scope:
- Local/public-host image artifact manifest construction for Zhihu fallback images.
- No account upload, no editor preview, no sync, no publish.

Implemented:
- createZhihuImageArtifactManifest(options)
- inferZhihuImageArtifactFormat(input)
- inferZhihuImageHostStatus(src)

Behavior:
- Infers JPG/JPEG/PNG/GIF formats from MIME, file names, or final URLs.
- Classifies final image hosts as platform-hosted, public-https, local-only, missing, or blocked.
- Derives markdownReferences from referenced artifacts when the caller does not supply them.
- Requires local fallback records to carry exists:true, positive bytes, non-empty alt, and semantic caption or textFallback.
- Requires platform upload proof to be explicit uploaded:true plus a recognized platform-hosted final URL.
- Rejects fake hostStatus overrides, public URLs marked as uploaded proof, local/blob/data/http/private URLs, and incomplete platform-upload manifests.
- Still relies on validateZhihuImageArtifactManifest() for the final preflight decision.

Regression coverage:
- Unit tests cover format inference, host inference, public HTTPS fallback manifests, explicit platform-upload manifests, and rejected fake host/upload metadata.
- Cross-platform export tests cover creating a Zhihu manifest from public host metadata before convertToNativeFormat(..., 'zhihu').
