## 一、项目定位（基于用户UI设计）

### 1.1 核心理念

这不是一个简单的 Markdown 编辑器，而是一个**内容创作工作站**：

```
信息聚合 → AI处理 → 人工编辑 → 多格式导出
```

## 三、数据模型

### 3.1 核心实体

```typescript
// 分类
interface Category {
  id: string
  name: string
  icon?: string
  articleCount: number
  createdAt: Date
}

// 资讯
interface Article {
  id: string
  categoryId: string
  sourceUrl: string
  sourceName: string        // "apple/ml-starflow"
  title: string
  description: string
  
  // 元数据
  authors: string[]
  publishedAt?: Date
  
  // 解析内容
  rawContent: string
  links: string[]
  images: string[]
  
  // AI内容
  aiSummary?: string
  
  // 状态
  score: number             // 10.0
  tags: string[]
  status: 'new' | 'read' | 'processed'
  
  createdAt: Date
}

// 编辑内容
interface EditedContent {
  id: string
  articleId: string
  
  title: string
  body: string
  transcript: string        // 口播稿
  
  selectedLinks: string[]
  selectedImages: string[]
  
  versions: Version[]
  currentVersionId: string
}

// 版本
interface Version {
  id: string
  label: string             // "v1"
  title: string
  body: string
  transcript: string
  createdAt: Date
}
```

## 四、业务模块

### 4.1 模块清单

| 模块 | 功能 | 优先级 |
|------|------|--------|
| **CategoryModule** | 分类 CRUD、筛选 | P0 |
| **ArticleModule** | 资讯导入、列表、状态管理 | P0 |
| **ParserModule** | URL解析、内容提取 | P0 |
| **PreviewModule** | 内容预览、元数据显示 | P0 |
| **EditorModule** | 多模式编辑（标题/正文/口播稿）| P0 |
| **VersionModule** | 版本管理、历史 | P1 |
| **AIModule** | 摘要生成、覆盖/增量生成 | P1 |
| **ResourceModule** | 链接/图片选择管理 | P1 |
| **ExportModule** | 微信/Markdown/HTML导出 | P0 |
| **ThemeModule** | 10种预设主题 | P1 |

### 4.2 业务流程

```
1. 添加资讯
   用户输入URL → ParserService解析 → 提取元数据 → 保存到IndexedDB

2. 分类管理
   显示分类列表 → 点击分类 → 筛选资讯列表

3. 内容处理
   选择资讯 → 显示预览 → 点击"AI生成" → 生成标题/正文/口播稿

4. 编辑内容
   切换编辑模式 → 修改内容 → 自动保存版本

5. 导出发布
   选择主题预设 → 预览效果 → 一键复制到微信
```

## 六、关键技术细节

### 6.1 微信导出（参考 doocs/md）

```typescript
// 核心流程
async function exportToWechat(content: string, theme: ThemePreset) {
  // 1. Markdown → HTML
  const html = marked.parse(content)
  
  // 2. 应用主题CSS
  const styledHtml = applyTheme(html, theme)
  
  // 3. CSS内联（juice）
  const inlinedHtml = juice(styledHtml, { removeStyleTags: true })
  
  // 4. 微信兼容性处理
  const wechatHtml = postProcessForWechat(inlinedHtml)
  
  // 5. 复制到剪贴板
  await navigator.clipboard.write([
    new ClipboardItem({ 'text/html': new Blob([wechatHtml], { type: 'text/html' }) })
  ])
}
```
