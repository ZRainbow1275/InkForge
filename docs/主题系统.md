## 一、主题架构

### 1.1 设计理念

**双层架构**：基础主题 + 参数化预设

```
基础主题 (3个)
    ├── default (经典)  ─┐
    ├── grace (优雅)    ─┼─ CSS 骨架
    └── simple (简洁)   ─┘

微信文章预设 (12个)
    └── 每个预设 = 基础主题 + 特定参数
        ├── 主题色 (primaryColor)
        ├── 字体族 (fontFamily)
        ├── 行高 (lineHeight)
        ├── 首行缩进 (firstLineIndent)
        └── 其他开关...

小红书预设 (5个)
    └── emoji 装饰 + 标题风格 + 分割线
        ├── 清新少女 / 极简高级 / 温暖治愈
        └── 科技数码 / 自然清新

知乎预设 (3个)
    └── 学术风格 + 代码主题 + 引用格式
        ├── 学术论文 / 技术博客
        └── 深度评论
```

### 1.2 预设接口

```typescript
// stores/theme.ts
export interface ThemePreset {
    id: string
    name: string
    baseTheme: 'default' | 'grace' | 'simple'
    primaryColor: string
    fontFamily: 'sans' | 'serif' | 'mono'
    fontSize: number
    lineHeight: number
    firstLineIndent: boolean
    textAlign: 'left' | 'justify'
    macCodeBlock: boolean
    codeLineNumbers: boolean
    footnotes: boolean
}
```

### 3.1 生成逻辑

```typescript
// stores/theme.ts - generatedCSS
const generatedCSS = computed(() => {
    const fontFamilyMap = {
        sans: '-apple-system-font, BlinkMacSystemFont, "Helvetica Neue", "PingFang SC"...',
        serif: 'Georgia, "Noto Serif SC", "Source Han Serif SC"...',
        mono: '"Fira Code", "JetBrains Mono", Consolas...'
    }

    return `
/* InkForge Generated Theme CSS */
.preview-content {
    font-family: ${fontFamilyMap[fontFamily.value]};
    font-size: ${fontSize.value}px;
    line-height: ${lineHeight.value};
    color: #333;
    text-align: ${textAlign.value};
}

.preview-content p {
    margin-bottom: 1.5em;
    ${firstLineIndent.value ? 'text-indent: 2em;' : ''}
}

.preview-content h2 {
    color: ${primaryColor.value};
    border-bottom: 2px solid ${primaryColor.value};
}

.preview-content blockquote {
    border-left: 4px solid ${primaryColor.value};
    background: ${primaryColor.value}10;
}

.preview-content a {
    color: ${primaryColor.value};
}

${customCSS.value}
`.trim()
})
```

### 3.2 导出时 CSS 生成

```typescript
// services/export.ts - generateThemeCSS
function generateThemeCSS(preset: ExportPreset): string {
    const fontFamily = {
        'sans-serif': '...',
        'serif': '...',
        'monospace': '...'
    }[preset.fontFamily]

    return `
#nice {
    font-family: ${fontFamily};
    font-size: ${preset.fontSize};
    line-height: 1.8;
    color: #333;
    padding: 16px;
}
/* ... 更多样式 */
${preset.customCSS || ''}
`
}
```

## 四、自定义 CSS

### 4.1 自定义入口

用户可通过 `theme.customCSS` 追加自定义样式：

```typescript
const themeStore = useThemeStore()
themeStore.customCSS = `
    #nice h2::before {
        content: '📌';
        margin-right: 8px;
    }
`
```

### 4.2 CSS 编写规范

> **核心约束**：微信公众号编辑器剥离所有 `<style>` 标签

| ✅ 支持 | ❌ 不支持 |
|---------|----------|
| 元素选择器 `h2 {}` | `:hover` 伪类 |
| 类选择器 `.class {}` | `@media` 媒体查询 |
| ID 选择器 `#id {}` | CSS 变量 `var()` |
| 后代选择器 `#nice h2` | `::before` (部分) |

### 4.3 推荐 CSS 变量替换

| 变量 | 替换为 |
|------|--------|
| `var(--md-primary-color)` | 具体颜色值 |
| `var(--foreground)` | `#3f3f3f` |
| `var(--blockquote-background)` | `#f7f7f7` |

## 五、主题应用流程

### 5.1 编辑时预览

```
用户选择预设 → applyPreset(presetId) → 更新 Store 响应式状态
     ↓
generatedCSS 自动更新 → 预览面板立即反映
```

### 5.2 导出时

```
调用 convertToWechat(html, preset)
     ↓
generateThemeCSS(preset) → 生成完整 CSS
     ↓
juice(html + css) → CSS 内联到 HTML 元素
     ↓
postProcess → 替换 CSS 变量、修复兼容性
     ↓
复制到剪贴板 → 粘贴到微信
```
