## 三、服务层 (`src/services/`)

### 3.1 目录结构

```
services/
├── ai.ts               # AI 服务 (OpenAI/Claude)
├── error.ts            # 错误处理 (AppError, Logger)
├── export/             # 导出服务（模块化架构）
│   ├── index.ts        # 统一导出入口 (convertToPlatform, getPlatformPresets)
│   ├── types.ts        # 类型定义 (ExportOptions, CodeTheme, Platform等)
│   ├── utils.ts        # 公共工具 (代码高亮, Alert块, 表格增强, 统计计算)
│   ├── themes.ts       # 微信主题预设 (12种) + CSS 生成
│   ├── wechat.ts       # 微信导出引擎 (8步管线)
│   ├── xiaohongshu.ts  # 小红书导出引擎 (5种预设, emoji装饰)
│   ├── xiaohongshu-text.ts  # 小红书纯文本导出引擎（无 HTML 依赖）
│   ├── zhihu.ts        # 知乎导出引擎 (3种预设, 学术引用)
│   ├── zhihu-markdown.ts    # 知乎 Markdown 导出引擎（原生 Markdown 输出）
│   ├── quality-detector.ts  # 三平台质量检测器（字数/图片/链接/格式合规）
│   ├── platform-css.ts      # 三平台 CSS 属性支持矩阵（兼容性校验）
│   ├── css-validator.ts     # CSS 合规性验证器（平台规则匹配）
│   └── shared-typography.ts # 共享排版配置（字体/字号/行高/间距统一）
├── parser/             # URL 解析服务（模块化）
│   ├── index.ts        # 解析入口
│   ├── extractor.ts    # 内容提取器
│   ├── proxy.ts        # CORS 代理
│   ├── request.ts      # HTTP 请求封装
│   ├── ssrf.ts         # SSRF 防护
│   └── types.ts        # 解析类型定义
├── parser.ts           # URL 解析服务（兼容入口）
├── repository.ts       # Repository 抽象层
└── security/           # 安全服务
    ├── index.ts        # 安全模块入口
    ├── html-sanitizer.ts   # HTML 消毒
    ├── css-sanitizer.ts    # CSS 消毒
    ├── policy-manager.ts   # 安全策略管理
    └── types.ts        # 安全类型定义
```

### 3.2 服务详解

#### `export/` - 导出服务（核心模块）

**模块化架构**：导出服务拆分为 13 个独立文件，职责清晰。

```typescript
// export/index.ts - 统一导出入口
export function convertToPlatform(
    html: string,
    platform: Platform,      // 'wechat' | 'xiaohongshu' | 'zhihu'
    presetId?: string,
    options?: ExportOptions
): string

export function getPlatformPresets(platform: Platform):
    ExportPreset[] | XiaohongshuPreset[] | ZhihuPreset[]
```

**功能矩阵**：

| 特性 | 微信 | 小红书 | 知乎 |
|------|------|--------|------|
| XSS 防护 | ✅ | ✅ | ✅ |
| 代码高亮（7主题） | ✅ | ✅ | ✅ |
| Mac 代码块 | ✅ | ❌ | ✅ |
| GitHub Alert 块 | ✅ | ✅ | ✅ |
| 表格增强 | ✅ | ✅ | ✅ |
| 外链转脚注 | ✅ | 剥离纯文本 | 学术引用格式 |
| 主题预设 | 12 种 | 5 种 | 3 种 |

#### `parser/` - URL 解析服务

```typescript
// parser/index.ts
export async function parseUrl(url: string): Promise<ParseResult>
export function calculateScore(result: ParseResult): number
```

**能力**：
- 通过 CORS 代理获取网页
- 提取标题、描述、作者
- 提取正文、链接、图片
- 计算内容质量分数
- SSRF 防护

#### `security/` - 安全服务

```typescript
// security/index.ts
export function sanitizeHtml(html: string): string
export function sanitizeCss(css: string): string
export function createSecurityPolicy(config): SecurityPolicy
```

#### `repository.ts` - 数据仓库


## 五、视图层 (`src/views/`)

### 5.1 目录结构

```
views/
├── immersive/              # 沉浸式视图子组件
├── HubView.vue             # 信息聚合中心 (27.7KB)
├── PublishView.vue         # 发布中心 — 多平台导出 (32.3KB) ★核心
├── SettingsView.vue        # 设置页面 (22.6KB)
├── ThemesView.vue          # 主题管理 (9.2KB)
├── WorkstationView.vue     # 工作站 — 编辑器主入口 (57.8KB) ★默认
└── NotFoundView.vue        # 404 页面 (0.9KB)
```

### 5.2 视图职责

| 视图 | 路由 | 职责 |
|------|------|------|
| `WorkstationView` | `/workstation` | 编辑器工作站，核心写作入口 |
| `PublishView` | `/publish` | 发布中心，多平台导出（微信/小红书/知乎） |
| `HubView` | `/hub` | 信息聚合中心，URL 解析与资讯管理 |
| `ThemesView` | `/themes` | 主题预设浏览与管理 |
| `SettingsView` | `/settings` | 应用设置（AI配置、安全设置等） |
| `NotFoundView` | `*` | 404 未找到页面 |
