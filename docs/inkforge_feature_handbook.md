# InkForge Studio 功能实现手册 (Feature Handbook v5.0)

> **版本**: 5.0 | **日期**: 2026-01-11
> **目标**: 打造面向微信公众号、小红书、知乎等平台的**专业级内容创作工作站**。
> **设计理念**: 苏联构成主义的**张力** + 瑞士秩序主义的**克制** + 东方美学的**轻盈**。
> **设计调性**: *"在克制中寻找张力，在留白中孕育气韵"*

---

## 🎨 第一章：设计哲学 (Design Philosophy)

### 1.1 核心理念：Ethereal Constructivism (空灵构成主义)

**设计公式**：
```
InkForge = (结构张力 × 几何秩序) ^ 东方气韵
```

| 维度 | 灵感来源 | 在 InkForge 中的演绎 |
|------|---------|---------------------|
| **结构 (Structure)** | **El Lissitzky (构成主义)** | 利用**非对称网格**与**悬浮层级**创造视觉张力。界面不是平面的，而是有纵深感的物理空间。 |
| **秩序 (Order)** | **Josef Müller-Brockmann (国际主义)** | 极度克制的排版。**Type is UI**。字号大小、粗细对比即是界面本身。去除多余的分割线和装饰。 |
| **气韵 (Spirit)** | **原研哉 (White)** | 感受"纸"的物理性。界面要有呼吸感 (Breathing Space)。光影不仅是装饰，而是表达"层级"的语言。 |

### 1.2 材质与光影 (Materiality & Light)

我们定义三种核心材质，构建界面的物理质感：

1.  **Rice Paper (宣纸)**: 编辑器背景。微纹理，不完全纯白 (`#FAFBFC`)，吸收光线，提供最舒适的书写阻尼感。
2.  **Frosted Glass (毛玻璃)**: 悬浮面板 (Manager/Inspector)。高斯模糊 (`backdrop-filter`)，让背景色块隐约透出，体现"轻盈"与"通透"。
3.  **Solid Steel (钢)**: 关键操作按钮。高饱和度，锐利圆角，体现构成主义的工业力量感。

### 1.2.1 留白节奏 (Space Rhythm)

> *"留白不是空，而是满的另一种形式。"* — 原研哉

我们采用 **8px 基础网格** 构建空间韵律：

| 空间类型 | 尺寸 | 应用 |
|---------|------|------|
| **Micro** | 4px | 图标与文字间距、行内元素 |
| **Small** | 8px | 按钮内边距、列表项间距 |
| **Medium** | 16px | 卡片内边距、段落间距 |
| **Large** | 32px | 区块分隔、面板间距 |
| **Macro** | 64px | 主要区域留白、视觉呼吸区 |

### 1.2 色彩系统 (Color Tokens)

```css
:root {
  /* 背景 */
  --bg-base: #FAFBFC;           /* 微灰白 */
  --bg-surface: #FFFFFF;         /* 纯白面板 */

  /* 强调 (构成主义) */
  --accent-primary: #D32F2F;     /* 构成主义红 - 仅用于关键 CTA */
  --accent-secondary: #1565C0;   /* 瑞士蓝 - 辅助强调 */
  
  /* 中性 */
  --text-primary: #263238;       /* 深灰 */
  --text-secondary: #607D8B;     /* 中灰 */
  --text-muted: #B0BEC5;         /* 浅灰 */
  --border: #ECEFF1;             /* 极浅边框 */
  
  /* 语义 */
  --success: #2E7D32;
  --warning: #F57C00;
  --error: #C62828;

```

**色温平衡 (Color Temperature)**:
*   **冷色主导**: 界面整体维持冷灰调 (Blue-Grey)，传达专业、理性。
*   **暖色点睛**: 仅在「发布」「保存成功」等情感高点使用暖色 (构成主义红 #D32F2F)。
*   **禁止**: 大面积使用高饱和暖色，避免视觉疲劳。

### 1.3 字体组合 (Typography Stack)

| 用途          | 字体           | 字重    | 备注           |
| ------------- | -------------- | ------- | -------------- |
| **界面标题**  | Inter          | 600-700 | 瑞士风格无衬线 |
| **文章正文**  | Noto Serif SC  | 400-500 | 东方书卷气     |
| **代码/技术** | JetBrains Mono | 400     | 等宽高辨识度   |
| **数字/数据** | DIN Alternate  | 500     | 德式工业风     |

### 1.3.1 微排版美学 (Micro-Typography)

> **美感验证**: 真正的品味体现在不可见的细节。

*   **黄金比行高**: 正文行高严格遵循 `font-size * 1.618`。
*   **光学对齐**: 标点悬挂 (Optical Margin Alignment)，确保文本边缘视觉整齐。
*   **流体字号**: `clamp(16px, 1.2vw, 18px)`，随视窗宽度"呼吸"调整。

### 1.4 动效原则 (Motion Language)

| 动效类型     | 缓动函数                            | 时长  | 用途              |
| ------------ | ----------------------------------- | ----- | ----------------- |
| **面板展开** | `cubic-bezier(0.16, 1, 0.3, 1)`     | 300ms | 侧边栏、Inspector |
| **悬浮菜单** | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 200ms | 弹性弹出效果      |
| **页面过渡** | `ease-out`                          | 200ms | 路由切换          |
| **微交互**   | `ease-in-out`                       | 150ms | 按钮、图标        |

**原则**：

- 所有动画必须支持 `prefers-reduced-motion` 媒体查询
- 动画服务于功能，而非装饰
- 使用 CSS 原生动画优先，复杂场景用 GSAP


### 1.5 通感设计 (Synesthesia Design)

*   **听觉 (Auditory)**:
    *   **Mechanical Click**: 模拟 Leica 相机快门的清脆声，仅在"发布"或"保存"成功时极轻微触发。
    *   **Paper Rustle**: 侧边栏展开时，伴随极低分贝的纸张摩擦白噪音。
*   **触觉 (Haptic)**:
    *   **Impact**: 输入回车换行时，给予微弱的震动反馈（Mobile端）。

### 1.6 图标哲学 (Icon Philosophy)

> *"图标是文字的影子，而非替代品。"*

| 原则 | 描述 |
|------|------|
| **线面结合** | 默认使用 1.5px 线性图标 (Lucide)；激活态填充为实心。 |
| **光学校正** | 圆形图标视觉尺寸需比方形略大 (+2px) 以达到感知平衡。 |
| **动态语义** | 图标不仅是静态符号：鼠标悬停时微微「呼吸」放大 (scale 1.05)。 |
| **去装饰化** | 拒绝渐变、阴影、3D 效果。保持扁平、单色、几何。 |

### 2.1 动态力场布局 (Dynamic Force Field)


### 2.2 交互美学：以动传神 (Kinetic Elegance)

**1. 磁吸感应 (Magnetic Hover)**
并不是简单的 `hover` 效果。当鼠标靠近面板边缘 20px 时，面板边缘会有微小的**位移吸附**效果（视差移动），暗示"这里有东西"，再继续移动才完全展开。

**2. 液体过渡 (Liquid Flow)**
面板的展开不是"推挤"，而是**基于物理弹簧**的滑入。
`spring(mass: 1, stiffness: 100, damping: 20)`
给用户一种"拉开抽屉"或"滑开纸张"的物理愉悦感。

**3. 情绪化排版 (Emotional Type)**
当用户打字速度加快时，光标的闪烁频率和跟随动画会变得更灵动（Trail Effect）。当删除文字时，文字不是瞬间消失，而是有一个极快的"飞溅"或"溶解"动画。

### 2.2 面板行为矩阵

| 面板              | 默认宽度 | 折叠触发               | 展开触发          | 快捷键           |
| ----------------- | -------- | ---------------------- | ----------------- | ---------------- |
| **Manager**       | 240px    | 点击折叠按钮 / `Cmd+B` | 悬停左边缘 (12px) | `Cmd+B`          |
| **Stage**         | 320px    | 点击折叠按钮 / `Cmd+P` | 悬停右边缘        | `Cmd+P`          |
| **Inspector**     | 280px    | 点击关闭 / `Cmd+I`     | 点击 Stage 内元素 | `Cmd+Shift+I`    |
| **All Collapsed** | —        | `F11`                  | `Esc`             | `F11` (专注模式) |

### 2.3 仪式感交互 (Interaction Rituals)

**1. "入定"仪式 (The Dive)**
进入专注模式不仅是 UI 的消失，而是**光线的收敛**。
屏幕边缘逐渐变暗 (Vignette)，灯光聚焦于中央纸张。外界噪音（UI 元素）消隐，仿佛置身深夜书房。

**2. "落款"仪式 (The Seal)**
点击发布时，不是弹出一个冷冰冰的 Modal，而是出现一个**浮雕质感**的印章动画，盖在文章末尾，确认"完稿"。
