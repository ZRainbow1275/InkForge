## 🚀 快速开始

### 环境要求

- Node.js ≥ 18.0.0
- pnpm ≥ 8.0.0 (推荐)

### 安装依赖

```bash
cd inkforge
pnpm install
```

### 启动开发服务器

```bash
pnpm dev
# 访问 http://localhost:5173
```

### 构建生产版本

```bash
pnpm build
```

## 🎯 项目定位

InkForge **不是**一个简单的 Markdown 编辑器，而是一个**内容创作工作站**：

```
信息聚合 → AI处理 → 人工编辑 → 多格式导出
```

### 核心功能

| 功能 | 描述 |
|------|------|
| **多平台预览** | 微信公众号、小红书、知乎实时预览 |
| **10种主题预设** | 论文翻译、法学研讨、行业研报等 |
| **复制 & 发布** | 生成带内联样式的 HTML，一键复制粘贴到平台编辑器 |
| **智能导出** | CSS 内联、外链转脚注、代码高亮 |
| **本地存储** | IndexedDB 离线优先，无需网络 |
| **AI 辅助** | 可集成 OpenAI/Claude API |

## 📐 核心架构

### 渲染管线（四层架构）

```
┌────────────┐     ┌────────────┐     ┌────────────┐     ┌────────────┐
│  Markdown  │ ──▶ │   marked   │ ──▶ │  Theme     │ ──▶ │   juice    │
│   Source   │     │   Parser   │     │   Apply    │     │  Inline    │
└────────────┘     └────────────┘     └────────────┘     └────────────┘
                                                                │
                                                                ▼
┌────────────┐     ┌────────────┐     ┌────────────┐     ┌────────────┐
│  WeChat    │ ◀── │  Platform  │ ◀── │  Variable  │ ◀── │  Structure │
│  Output    │     │   Adapt    │     │  Replace   │     │   Modify   │
└────────────┘     └────────────┘     └────────────┘     └────────────┘
```

### 数据流

```
┌─────────────────────────────────────────────────────────────┐
│                        用户操作层                            │
├─────────────────────────────────────────────────────────────┤
│  添加URL  │  选择分类  │  选择资讯  │  编辑内容  │  导出    │
└─────┬─────┴─────┬─────┴─────┬─────┴─────┬─────┴─────┬─────┘
      │           │           │           │           │
      ▼           ▼           ▼           ▼           ▼
┌─────────────────────────────────────────────────────────────┐
│                        服务层 (Services)                     │
├─────────────────────────────────────────────────────────────┤
│ ParserService │ ExportService │ AIService │ ErrorService    │
└───────────────┴───────────────┴───────────┴─────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────┐
│                        状态层 (Stores)                       │
├─────────────────────────────────────────────────────────────┤
│ ArticleStore │ CategoryStore │ EditorStore │ ThemeStore     │
└───────────────┴───────────────┴─────────────┴───────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────┐
│                        存储层 (Repository)                   │
├─────────────────────────────────────────────────────────────┤
│          IndexedDB (Dexie.js) - 离线优先架构                 │
└─────────────────────────────────────────────────────────────┘
```

## 📁 项目结构概览

```
inkforge/
├── src/
│   ├── components/     # 组件目录
│   │   ├── ai/         # AI 功能组件
│   │   ├── article/    # 资讯列表
│   │   ├── category/   # 分类面板
│   │   ├── cms/        # CMS 组件
│   │   ├── editor/     # 编辑器组件
│   │   ├── export/     # 导出组件
│   │   ├── layout/     # 布局组件
│   │   └── preview/    # 预览组件
│   ├── services/       # 业务服务
│   │   ├── ai.ts       # AI 服务
│   │   ├── error.ts    # 错误处理
│   │   ├── export.ts   # 导出服务 (核心)
│   │   ├── parser.ts   # URL 解析
│   │   └── repository.ts # 数据仓库
│   ├── stores/         # Pinia 状态
│   │   ├── ai.ts       # AI 状态
│   │   ├── article.ts  # 资讯状态
│   │   ├── category.ts # 分类状态
│   │   ├── editor.ts   # 编辑器状态 (FSM)
│   │   └── theme.ts    # 主题状态
│   ├── views/          # 页面视图
│   │   ├── ImmersiveView.vue  # 沉浸式 (默认)
│   │   ├── CMSView.vue        # CMS 模式
│   │   ├── NexusView.vue      # Nexus 模式
│   │   ├── EditorView.vue     # 编辑器 (Legacy)
│   │   ├── ClientView.vue     # 客户端视图
│   │   └── WorkspaceView.vue  # 工作区
│   ├── styles/         # 样式文件
│   ├── types/          # TypeScript 类型
│   ├── utils/          # 工具函数
│   ├── router/         # 路由配置
│   └── schemas/        # Zod 验证模式
├── docs/               # 开发文档 (本目录)
└── package.json
```
