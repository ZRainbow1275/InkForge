## 1. 项目概述与开发目标

### 1.1 项目定位

InkForge 是一个面向内容创作者的多平台 Markdown 富文本编辑器工作站，基于 Vue 3 + TypeScript + Tauri 构建。核心目标是让创作者在一个统一的工作环境中完成从构思、写作、排版到发布的全流程。

### 1.2 本轮开发目标

| 优先级 | 目标 | 验收标准 |
|--------|------|---------|
| P0 | 消除所有 Mock 数据 | 零硬编码假数据，所有数据来自真实源 |
| P0 | 编辑器渲染修复 | 去除大黑框，预览区美观且精确匹配平台效果 |

| P1 | 素材库真实化 | 本地文件管理、图片预览、与编辑器联动 |
| P1 | 大纲编辑器 | 可视化大纲、AI 协作、实时同步到正文 |

### 1.3 现有功能审计

#### 已实现（真实功能）
- IndexedDB 数据持久化（Dexie ORM）
- 分类管理 CRUD（Zod 校验 + Repository 模式）
- 文章管理 CRUD（URL 解析 + 手动添加）
- 编辑器 FSM 状态机（idle → loading → ready → saving → error）
- 版本控制后端逻辑（创建/切换/上限管理）
- 多平台导出引擎（微信/小红书/知乎，11步/10步/8步管线）
- 主题系统（12 微信 + 5 小红书 + 3 知乎预设）
- 代码高亮（7 主题，hljs class → inline style 转换）
- CSS 内联化（juice 库）
- 安全防护（DOMPurify, Zod Schema, CSP, SSRF 防护）
- Ollama 本地 AI（7 个生成功能，Tauri IPC 代理）
