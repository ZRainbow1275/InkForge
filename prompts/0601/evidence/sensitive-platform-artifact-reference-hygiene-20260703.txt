Sensitive Platform Artifact Reference Hygiene - 2026-07-03

Scope:
- Local committed-proof hygiene for StyleProofManifest artifact references.
- No platform action, no phone preview, no upload, no sync, no scheduled send, no publish.
- No local browser profile, QR payload, account screenshot, HAR, cookie, token, platform
  screenshot path, or raw platform capture is part of this committed evidence.

Problem:
- Real platform verification can leave local WeChat backend screenshots and QR captures near
  text evidence.
- A proof manifest must not become claimable or committable simply because it sets
  safeForCommit:true while its id, label, or artifactRef still points at account-state material.

Implemented:
- Renamed the sensitive proof pattern list to SENSITIVE_ARTIFACT_TEXT_PATTERNS.
- Sensitive artifact detection now checks artifact id, label, and artifactRef.
- Added account/backend/creator/editor/logged-in screenshot wording guards.
- Added WeChat paste PNG filename guards for preview QR, cover crop, cover vessel, account,
  backend, and vessel captures.
- Preserved redacted local paste HTML references such as
  prompts/0601/evidence/wechat-paste/flagship-amber.html.

Regression coverage:
- A committed WeChat cover vessel PNG reference marked safeForCommit:true is still classified as
  sensitive and unsafe-commit.
- A committed artifact whose label says WeChat backend account screenshot redaction is missing is
  still classified as sensitive and unsafe-commit.
- A redacted local WeChat paste HTML reference under the same evidence tree remains accepted.
