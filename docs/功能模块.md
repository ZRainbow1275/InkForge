### 2.4 微信导出模块

#### 2.4.1 导出管线

```typescript
// services/export/wechat.ts - convertToWechat
function convertToWechat(html: string, preset: ExportPreset, options: ExportOptions): string {
    // 1. XSS 防护
    let result = DOMPurify.sanitize(html)

    // 2. 代码高亮（多主题支持）
    result = highlightCodeBlocks(result, options.enableLineNumbers, options.enableMacCodeBlock, options.codeTheme)

    // 3. GitHub Alert 块渲染
    result = renderAlertBlocks(result)

    // 4. 外链转脚注
    result = convertLinksToFootnotes(result)

    // 5. 应用主题 CSS
    const styledHtml = `<style>${generateThemeCSS(preset)}</style>${result}`

    // 6. CSS 内联 (juice)
    result = juice(styledHtml, {
        inlinePseudoElements: true,
        preserveImportant: true
    })

    // 7. 表格增强（条纹行、圆角、主色表头）
    result = enhanceTableStyles(result, preset.primaryColor)

    // 8. 后处理补丁（blockquote/figcaption/SVG/嵌套列表等）
    result = postProcessForWechat(result)

    return result
}
```

#### 2.4.2 后处理补丁

| 补丁 | 方法 | 说明 |
|------|------|------|
| CSS 变量替换 | 正则替换 | `var(--color)` → 具体值 |
| 图片属性转样式 | DOM 操作 | `width="100"` → `style` |
| 嵌套列表修复 | DOM 操作 | `li > ul` 移为兄弟 |
| SVG 边界修复 | DOM 操作 | 添加空白分隔符 |
| Alert 块渲染 | `renderAlertBlocks()` | `[!NOTE]` `[!TIP]` 等 GitHub 风格 |
| 表格增强 | `enhanceTableStyles()` | 条纹行、圆角、主色表头 |
| blockquote 增强 | 正则替换 | 左色条+圆角+浅背景 |
| figcaption 样式 | 正则替换 | 居中、斜体、小号灰色 |

### 4.2 双轨导出架构

导出服务采用**双轨管线**设计，根据使用场景选择最优输出格式：

```
                        ┌──────────────────────┐
                        │    Markdown 原文       │
                        └──────────┬───────────┘
                                   │
                    ┌──────────────┼──────────────┐
                    ▼                              ▼
         ┌──────────────────┐           ┌──────────────────┐
         │  convertToPlatform│           │convertToNativeFormat│
         │  (预览模式)        │           │  (原生格式模式)     │
         └────────┬─────────┘           └────────┬─────────┘
                  │                               │
      ┌───────┬───┴───┬───────┐       ┌───────┬──┴──┬───────┐
      ▼       ▼       ▼       ▼       ▼       ▼     ▼       ▼
   微信     小红书   知乎    (穷举)  微信    小红书  知乎   (穷举)
  HTML      HTML    HTML   never  HTML    纯文本  Markdown never
  内联CSS   内联CSS  内联CSS       内联CSS  +emoji  清洁MD
```

#### 4.2.1 预览模式 — `convertToPlatform()`

输出内联 CSS HTML，用于编辑器内实时预览和微信公众号复制粘贴。

```typescript
// services/export/index.ts
async function convertToPlatform(
    markdown: string,
    platform: Platform,   // 'wechat' | 'xiaohongshu' | 'zhihu'
    options?: {
        presetId?: string
        exportOptions?: ExportOptions
        overrides?: RenderOverrides  // Inspector/Settings 动态覆盖
    }
): Promise<string>
```

**特点**：
- 三平台统一走 `marked.parse()` → HTML → 平台引擎 → 内联 CSS HTML
- 支持 `RenderOverrides` 动态覆盖主色和字体（Inspector 面板联动）
- 空文档守卫：纯空白内容直接返回空字符串
- TypeScript `never` 穷举检查确保新增平台不会遗漏

#### 4.2.2 原生格式模式 — `convertToNativeFormat()`

按平台特性输出最优格式，推荐用于实际发布场景。

```typescript
// services/export/index.ts
async function convertToNativeFormat(
    markdown: string,
    platform: Platform,
    options?: {
        presetId?: string
        exportOptions?: ExportOptions
        overrides?: RenderOverrides
        xiaohongshuTextOptions?: XiaohongshuTextOptions
        zhihuMarkdownOptions?: ZhihuMarkdownOptions
        includeQualityReport?: boolean  // 默认 true
    }
): Promise<NativeExportResult>
```

**平台输出格式差异**：

| 平台 | 输出格式 | 引擎 | 说明 |
|------|---------|------|------|
| 微信 | `html` | `convertToWechat` | 微信仅支持内联 CSS HTML |
| 小红书 | `text` | `markdownToXiaohongshuText` | 跳过 HTML 管线，Markdown → 纯文本 + emoji |
| 知乎 | `markdown` | `markdownToZhihuClean` | 跳过 HTML 管线，Markdown → 清洁 Markdown |

**统一返回结构**：
```typescript
interface NativeExportResult {
    format: 'html' | 'text' | 'markdown'
    content: string
    platform: Platform
    qualityReport?: QualityReport  // 可选的质量检测报告
}
```

#### 4.3.2 纯文本引擎 (`xiaohongshu-text.ts`)

小红书平台只支持纯文本 + emoji，不支持任何 HTML/CSS/Markdown 格式。本引擎将 Markdown **直接转换**为纯文本（跳过 HTML 管线），并自动注入 emoji 装饰。

**转换管线（18 步）**：
```
Markdown → 预处理 → 代码块转换 → 表格列表化 → Mermaid提示
→ LaTeX降级 → 标题emoji化 → 列表美化 → 引用块转文本
→ Alert块转换 → 链接→搜索提示 → 图片→文字提示
→ 水平线装饰 → 任务列表emoji → 清理MD语法 → 自动分段
→ emoji密度调整 → 签名添加 → 最终清理 → 输出
```

**5种 emoji 风格**：

| 风格 | H1 | H2 | H3 | 列表标记 | 分割线 |
|------|----|----|-----|---------|--------|
| `fresh` 清新少女 | 🌸 | 🌷 | 💐 | ✅ | ━━━━━━ |
| `simple` 极简高级 | ◆ | ◇ | ▫ | · | · · · · · |
| `warm` 温暖治愈 | 🧡 | 💛 | 🤎 | 🌻 | ✦ ✦ ✦ |
| `tech` 科技数码 | ⚡ | 💫 | ✦ | 🔹 | ▪️▪️▪️▪️ |
| `nature` 自然清新 | 🌿 | 🍀 | 🌱 | 🍃 | · · 🌿 · · |

**配置选项**（`XiaohongshuTextOptions`）：
```typescript
interface XiaohongshuTextOptions {
```

**核心转换规则**：
| Markdown 元素 | 纯文本转换 | 说明 |
|--------------|-----------|------|

| `> 引用` | `💬 引用内容` | 合并多行引用 |

| `![图片](url)` | `📷 见图片1` | 序号化文字提示 |
| 代码块 (<=5行) | 文本引用框 | 短代码保留 |
| 代码块 (>5行) | `💻 代码较长，建议截图展示` | 长代码提示截图 |
| 表格 | 列表化描述 | 表头/数据逐行展开 |

#### 4.4.2 Markdown 引擎 (`zhihu-markdown.ts`)

知乎平台原生支持 Markdown（含 LaTeX、代码块、表格）。本引擎采用**"减法"策略**——清理不兼容内容，保留原始 Markdown 语法。

**转换管线（10 步）**：
```
Markdown → 保护LaTeX → 保护代码块 → 保护行内代码
→ 清理HTML标签 → 清理style/class → 转换GFM扩展
→ 任务列表→emoji → 清理平台特有格式 → 恢复保护内容 → 最终清理
```

**配置选项**（`ZhihuMarkdownOptions`）：
```typescript
interface ZhihuMarkdownOptions {
    preserveLatex?: boolean       // 保留 LaTeX 公式 (默认 true)
    convertTaskLists?: boolean    // 转换任务列表为 emoji (默认 true)
    mermaidHandling?: 'prompt' | 'remove'  // Mermaid 处理方式 (默认 'prompt')
    cleanGfmExtensions?: boolean  // 清理 GFM 扩展语法 (默认 true)
}
```

**返回结果**（`ZhihuMarkdownResult`）：
```typescript
interface ZhihuMarkdownResult {
    markdown: string             // 清洁 Markdown 内容
    mermaidCount: number         // 检测到的 Mermaid 块数量
    taskListCount: number        // 转换的任务列表数量
    cleanedHtmlTags: string[]    // 清理的 HTML 标签列表
    latexCount: number           // LaTeX 公式数量（已保留）
}
```

**核心转换规则**：
| 元素 | 处理方式 | 说明 |
|------|---------|------|
| LaTeX `$...$` / `$$...$$` | 保留 | 知乎原生支持 |
| 代码块 | 保留 | 知乎原生支持 |
| Mermaid | 转引用提示 / 移除 | 知乎不支持 Mermaid 渲染 |
| HTML 标签 | 清理 | 保留文本内容 |
| `style` / `class` 属性 | 移除 | 知乎会过滤 |
| `[!NOTE]` 等 GFM Alert | 转 `> **注意：**` 引用块 | 降级为标准引用 |
| `- [x]` 任务列表 | `- ✅` | emoji 替代复选框 |
| Front Matter | 移除 | 知乎不支持 |
| HTML 注释 | 移除 | 清理非内容元素 |

### 4.5 质量检测系统

质量检测器（`quality-detector.ts`）在导出前自动检测内容是否符合目标平台的要求，返回结构化的质量报告。

#### 4.5.1 API 接口

```typescript
// 单平台检测
function detectQuality(markdown: string, platform: Platform): QualityReport

// 全平台批量检测（适合未选定平台时的预览场景）
function detectQualityAll(markdown: string): Record<Platform, QualityReport>

// 快速检测：仅返回是否通过
function quickCheck(markdown: string, platform: Platform): boolean

// 按严重度过滤问题
function filterIssues(report: QualityReport, severity: QualityIssueSeverity): QualityIssue[]
```

#### 4.5.2 质量报告结构

```typescript
interface QualityReport {
    platform: Platform
    timestamp: number
    passed: boolean          // 无 error 级别问题即通过
    issues: QualityIssue[]
    stats: { errors: number; warnings: number; suggestions: number }
}

interface QualityIssue {
    id: string                          // 检测项 ID
    severity: 'error' | 'warning' | 'suggestion'
    message: string                     // 问题描述
    suggestion?: string                 // 修复建议
    location?: string                   // 问题位置
}
```
