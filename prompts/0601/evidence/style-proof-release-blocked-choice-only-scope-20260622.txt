Style Proof Release Blocked-Choice-Only Scope - 2026-06-22

Scope:
- Local committed-evidence release-gate classification only.
- No platform action, phone preview, upload, sync, scheduled send, platform preview, public
  rendering, or publish action was executed or claimed.

Problem:
- The previous local-conflict release blocker correctly stopped counting every external missing
  proof row, but it still counted aggregate local requirement gaps whose remaining missing rows
  were entirely blocked catalog choices.
- It also treated `zhihu-artifact-manifest` as a local artifact chore even though the Zhihu image
  manifest validator requires a publishable public HTTPS or platform-host final image source.

Implemented:
- `getCommittedStyleProofEvidenceReleaseGateReport()` now excludes
  `style-proof-manifest-requirement-missing` rows when their matching runbook steps show that the
  remaining `missing` count is fully explained by blocked catalog choices.
- `zhihu-artifact-manifest` is no longer part of the release local-conflict requirement set.
  Zhihu image manifest gaps remain unclaimable through public-host / external dependency gates
  until exact redacted public/platform host evidence exists.
- The operator action for a choice-only local conflict now says to reconcile committed proof rows
  that target catalog-blocked choices, without mentioning missing local artifact manifests.
