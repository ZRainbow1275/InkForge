XHS image artifact manifest runtime gate - 2026-06-09

Scope
-----

This slice adds a local preflight gate for Xiaohongshu image-page / cover /
long-image artifacts. It does not claim real Xiaohongshu upload, account sync,
preview, or publish success.

Implemented runtime contract
----------------------------

- `XhsImageArtifactManifest` records image artifact kind, pages, body references,
  optional configured limits, and per-page file/dimension/ratio/format/bytes/
  cover/reference/crop status.
- `validateXhsImageArtifactManifest()` emits blocking issues for:
  - empty or over-limit page count;
  - non-continuous, duplicated, or cover-not-first page order;
  - missing file existence proof;
  - missing or duplicated cover page;
  - body reference mismatch;
  - unsupported or dimension-mismatched ratio;
  - unsupported format;
  - missing, zero, or over-limit bytes;
  - crop overflow.
- `cropStatus=warning` or `cropStatus=unknown` remains a warning and does not
  become a fake local pass.
- `convertToNativeFormat(..., 'xiaohongshu')` accepts the optional manifest,
  merges manifest issues into the quality report, and returns
  `artifacts.xiaohongshuImageManifest` as local preflight evidence only.
- If no manifest is supplied, the previous Xiaohongshu native text behavior is
  unchanged.
