5. Public source refresh

Exa results used as supplementary current references:
- 135 official FAQ/tutorial pages separate ordinary copy, copy-to-editor, copy-to-WeChat,
  developer-tool HTML replacement, plugin transfer, and authorized save-sync. They also warn
  that ordinary copy paths can lose some SVG effects.
- Xiumi Chrome extension and sync API documentation separate plugin copy and credentialed sync
  from normal copy/paste; the sync API transfers HTML and images through authenticated server
  interfaces and image URL replacement.
- Xiaohongshu/Rednote current tools and guides still center on image cards/carousel pages,
  browser/canvas rendering, 3:4 or similar vertical ratios, manifest/page order, cover strength,
  and manual upload.
- Zhihu authoring tools still center on clean Markdown, Markdown/LaTeX, image upload/public
  hosts, Mermaid/Graphviz/diagram rasterization, and table simplification.

Grok Search / Grok Fetch:
- 135 SVG center fetch corroborated the taxonomy headings.
- Xiumi public homepage fetch only produced sparse slideshow content in this environment, so
  it was treated as weak supplementary input and did not loosen any rule.

Runtime rule outcome:
- The executable style catalog should expose richer user choices, but only `available` choices
  whose current InkForge renderer/artifact has enough evidence may count as usable.
- Mobile-only SVG, plugin transfer, sync draft, H5/design families, cover-thumbnail publishing,
  and official widgets must remain `blocked` or `unavailable` until their exact target gate is
  verified with real platform evidence.
