## 二、LaTeX 公式支持详解

### 行内公式
```markdown
这是行内公式 $E = mc^2$ 的示例
```
- 使用单 `$` 包裹
- 知乎编辑器原生渲染
- 支持标准 LaTeX 数学语法

### 块级公式
```markdown
$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$
```
- 使用双 `$$` 包裹
- 独立成行显示
- 支持多行公式

### LaTeX 兼容注意事项
1. **保留原始语法** — 知乎原生支持 `$...$` 和 `$$...$$`
2. **历史兼容方案** — 旧版知乎用图片方式：
   ```html
   <img src="https://www.zhihu.com/equation?tex=E=mc^2" />
   ```
   现在不需要此方案，直接使用 LaTeX 语法即可
3. **特殊字符转义** — `_` 在 Markdown 中可能被解析为斜体，需注意转义
4. **换行** — 公式内换行使用 `\\\\`（双倍反斜杠，因 Markdown 转义）

### 常用 LaTeX 语法参考
```latex
% 上下标
x^2, x_i, x_{i+1}

% 分数
\frac{a}{b}

% 根号
\sqrt{x}, \sqrt[n]{x}

% 求和/积分
\sum_{i=1}^{n} x_i
\int_{a}^{b} f(x) dx

% 矩阵
\begin{bmatrix} a & b \\ c & d \end{bmatrix}

% 希腊字母
\alpha, \beta, \gamma, \theta, \lambda

% 比较运算
\leq, \geq, \neq, \approx

% 集合
\in, \notin, \subset, \cup, \cap
```

## 四、图片处理

### 规则
- 知乎支持外链图片（但可能转存到知乎 CDN）
- 建议上传至知乎图床以确保持久可用
- 图片格式支持：PNG, JPG, GIF, WebP
- 无明确尺寸限制，但建议合理宽度

### 注意事项
```
1. 外链图片可能被知乎服务器抓取并转存
2. 部分被墙的图片源可能无法正常显示
3. Base64 图片不支持
4. SVG 图片不支持（需转为 PNG/JPG）
```

## 五、Markdown → 知乎转换策略

### 核心原则
**知乎的 Markdown 支持度最高**，大部分内容无需转换，保持原始 Markdown 即可。

### 需要处理的元素

| 元素 | 处理方式 | 原因 |
|------|---------|------|
| 内联 HTML/CSS | 清理移除 | 知乎不渲染 HTML |
| `style` 属性 | 清理移除 | 知乎过滤 style |
| `class` 属性 | 清理移除 | 知乎过滤 class |
| Mermaid 图表 | → 提示转图片 | 不支持 Mermaid 渲染 |
| 任务列表 `- [ ]` | → `- ☐` 或普通列表 | 不支持复选框 |
| 微信特有标签 | 清理移除 | 如 `<section>` 等 |
| GFM 警告块 | → 引用块 `>` | 不支持扩展语法 |
| 自定义组件 | 清理/降级 | 不支持自定义 HTML |

### 转换管线
```
Step 1: 检测并清理 HTML 标签和内联样式
Step 2: 保留标准 Markdown 语法
Step 3: 保留 LaTeX 公式 ($...$ / $$...$$)
Step 4: 保留代码块 (```)
Step 5: 保留表格 (| |)
Step 6: 保留超链接 ([text](url))
Step 7: Mermaid → 生成截图提示
Step 8: 任务列表 → 普通列表或 emoji 替代
Step 9: 清理微信/平台特有格式
Step 10: 输出 Clean Markdown
```

## 六、知乎导入方式

### 方式一：Markdown 导入功能
1. 打开知乎写文章页面
2. 点击右上角「导入」按钮
3. 选择 `.md` 文件
4. 知乎自动解析并渲染

### 方式二：复制粘贴
1. 复制 Markdown 原文
2. 粘贴到知乎编辑器
3. 知乎编辑器部分支持 Markdown 即时渲染

### 方式三：API 发布
- 知乎没有公开的发布 API
- 需要通过第三方工具或浏览器扩展

## 七、质量检测清单

### 发布前自动检测

| 检测项 | 规则 | 严重度 |
|--------|------|--------|
| 残留 HTML 标签 | 任何 `<tag>` | ⚠️ 警告（会被过滤） |
| 残留内联样式 | `style="..."` | ⚠️ 警告（会被过滤） |
| Mermaid 图表 | ` ```mermaid` | ⚠️ 警告（需转图片） |
| 任务列表 | `- [ ]` / `- [x]` | 💡 建议（转普通列表） |
| 图片可访问性 | 外链是否可达 | ⚠️ 警告 |
| SVG 图片 | `.svg` 后缀 | ⚠️ 警告（需转 PNG） |
| LaTeX 语法错误 | 不匹配的 `$` | ❌ 阻断 |
| 超长代码行 | > 120 字符/行 | 💡 建议（影响阅读） |
