# Style Proof Manifest Pack Report Evidence - 2026-06-09

Scope
- Added `getStyleProofManifestPackReport(manifests)`.
- The function is the local intake/reporting boundary for a batch of redacted style proof manifests.
- It does not create proof artifacts and does not change style availability.

Runtime Contract
- WeChat, Xiaohongshu, and Zhihu progress reports are calculated separately through
  `getPlatformStyleProofProgressReport()`.
- A manifest contributes only to the platform report whose catalog owns the manifest `choiceId`.
- Unknown choices and platform/choice mismatches are reported as pack issues.
- Duplicate artifact ids are reported as pack issues.
- Multiple artifact fingerprints for the same platform/style choice are reported as pack/progress
  issues. Progress must not merge evidence from different exported artifacts into one satisfied gate
  state.
- Blocked or unavailable catalog choices remain invalid progress rows even when all proof artifacts
  are present.
- Evidence-label-only manifests are not applied to every style choice.
