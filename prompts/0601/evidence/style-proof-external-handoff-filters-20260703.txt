Style Proof External Handoff Filters - 2026-07-03

Scope:
- Local CLI usability improvement for the committed style-proof external handoff packet.
- No browser action, no account action, no clipboard write, no phone preview, no upload, no sync,
  no scheduled send, no public-host verification, and no publish operation.

Implemented:
- Extended `pnpm -C inkforge style-proof:external-handoff` with read-only filters:
  - `--platform <wechat|xiaohongshu|zhihu>`
  - `--kind <phone-preview|external-account|public-host|unsafe-to-automate|mutating-platform>`
  - `--next-only`

Behavior:
- Default markdown output remains compatible with the previous external handoff CLI.
- Unfiltered `--json` still emits the raw committed handoff packet JSON.
- Filtered JSON includes:
  - filtered rows, next row refs, and next rows;
  - applied `filters`;
  - original `committedSummary`;
  - filtered `filteredSummary`.
- Filtered markdown prepends a CLI filter header before the handoff packet.
- The command still exits non-zero while `canClaimComplete=false`; filtering a row list does not
  claim proof completion.
- Usage errors, invalid filter values, missing filter values, conflicting output modes, and
  unknown arguments exit 2 before reading or claiming proof state.

Sanitization:
- Output is limited to committed handoff metadata and operator instructions.
- Output must not print local browser profile paths, cookies, tokens, HAR references, QR
  payloads, account screenshots, draft URLs, publish URLs, input paths, output paths, or raw
  account/runtime material.
