# 总结 📘 微信公众号原子化排版·最佳实践指南

#### 一、 核心架构：从 Flexbox 回归 Table
*   **教训**：在微信（特别是安卓端）的 WebView 中，Flex 布局的 `flex-shrink`、`justify-content` 计算经常失效，导致元素错位或挤压。
*   **法则**：**结构决定一切。**
    *   涉及“左侧图标 + 右侧文字”的列表，**必须使用双栏表格 (`display: table` + `table-cell`)**。
    *   涉及“左右两端对齐”的元数据行，**必须使用表格**，而不是 `justify-content: space-between`。
    *   Table 提供了物理层面的隔离，确保文字永远不会跑偏。

#### 二、 样式重置：零信任原则 (Zero-Trust CSS)
*   **教训**：浏览器和微信编辑器会有默认的 `text-indent`（首行缩进）或 `margin`，导致不明原因的对齐错误（幽灵空格）。
*   **法则**：**显式归零。**
    *   在每一个容器级元素（div, p, h1-h6, li）上，尽量显式声明：
        ```css
        padding: 0; margin: 0; text-indent: 0;
        ```
    *   **字号锁定**：不要依赖继承，为每一个模块（Header, Body, Footer）显式指定 `font-size`（如 10px, 14px）。

#### 三、 工作流规范：对抗编辑器污染
*   **教训**：135编辑器等第三方工具在复制粘贴时，会携带大量的 `&nbsp;`（不换行空格），这是导致文字无法自动换行、布局撑爆的元凶。
*   **法则**：**纯文本粘贴。**
    *   **严禁**直接从 Word/网页 复制带格式的文本进入代码视图。
    *   **必须**使用“纯文本粘贴”或“清除格式”按钮，确保内容是纯净的字符。

#### 四、 移动端适配：寸土寸金
*   **教训**：电脑网页设计思维喜欢大留白（Padding 20px+），但这在手机上会严重压缩每行的字数，导致阅读体验破碎。
*   **法则**：**极致屏占比。**
    *   外容器 Padding 控制在 **2px - 5px**。
    *   内容区 Padding 控制在 **10px - 12px**。
    *   目标：**14px 字号下，每行能容纳 26-28 个汉字**。

#### 五、 视觉美学：字体与深色模式
*   **字体策略**：
    *   **正文**：坚守 **宋体 (Songti SC)**，14px。这是长文阅读舒适度与专业感的保证。
    *   **标题/强调**：使用 **黑体 (PingFang SC / Microsoft YaHei)**，营造现代感与冲击力。
*   **深色模式 (Dark Mode)**：
    *   尽量给深色背景的元素加上 **1px 的边框**。防止在微信强制反色（黑底变白字）时，深色块消失，导致文字悬空。

#### 六、 标准化组件 (The Footer)
*   每个变体必须包含一个 **通用 SVG/图片 容器**。
    *   属性：`width: 100%`，`line-height: 0`，`margin-top: 30px`。
    *   作用：用于无缝挂载你的个人名片、动态二维码或 Brand Logo。
