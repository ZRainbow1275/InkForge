## 第二组：T01 Typora 模式编辑器（20 题）

### 核心决策摘要

- **架构选择**：增强现有 `MarkdownHints.ts` 加 `cursorAware` 模式（T01-01=A），内部始终用 TipTap JSON 持久化，Source 模式仅显示序列化文本（T01-05=B），Source 端编辑器选 vue-codemirror（T01-06=A）。

## 本批次发现的矛盾 / 模糊点（共 5 条）

1. **T01-10 vs T01-18 重块元素进入规则冲突**：T01-18 选 B（光标进入即编辑，移出即渲染），作为统一规则涵盖图片；T01-10 选 C（图片双击才进入编辑）。图片该走"光标进入"还是"双击进入"需要后续 PRD 二选一，否则实现时两处规则打架。

2. **T01-16 中文输入法处理可能带来体验缺陷**：用户选了 C（不做特殊冻结），但嵌套 Mark 分别显示（T01-02=C）和各类 cursor-aware 渲染在 IME 组合态下极可能产生跳字/错位。验收阶段须有中文 IME 场景作为回归用例，否则 Ship 后大概率会被中文用户报 Bug。

3. **T02-01 vs T02-14 Hero 职责冲突**：T02-01 选 A（直接搬 WritingFlowCard——仅图表无按钮），T02-14 却要求 Hero 承担"继续创作"对象指向（暗含按钮/入口）。两者结合推断 Hero = 图表+继续创作入口的组合，需要 PRD 明确 Hero 新结构。

4. **T02-05 vs T02-15 全新安装引导策略冲突**：T02-05 选 C（单独 Onboarding Flow 取代空 Hub），T02-15 选 B（首次进入显示完整引导版 Hub）。两者路径不同——前者脱离 Hub 进入独立页，后者留在 Hub 但切形态。PRD 需选一，或明确"Onboarding Flow 结束后进入引导版 Hub"这种组合路径。

5. **G-11 权威顺序字母缺失**：用户将字母留空填 `?`，补充文字倾向选项 D 的"逐项判定"但又加了"最新日期文档优先"这个新约束。建议后续 PRD 按 D 处理，并把"最新日期文档优先"作为默认权威推导规则写入元规范。
