WeChat PC Paste Strong Gate - 2026-06-18

Scope:
- Local manifest validator hardening after the Kiln paste-safe WeChat negative runs.
- No platform action, phone preview, sync, upload, schedule, or publish was performed.

Implemented:
- Added optional `StyleProofArtifact` flags for ordinary WeChat PC paste proof:
  - `sameEditorTabVerified`
  - `pasteInputEventVerified`
  - `editorBodyMutationVerified`
  - `mojibakeFreeVerified`
- `pc-editor-paste-event` now requires one same `platform-editor` / `pc-paste` artifact to prove:
  - `ordinaryClipboardPasteVerified:true`
  - `sameEditorTabVerified:true`
  - `pasteInputEventVerified:true`
  - `editorBodyMutationVerified:true`
  - `mojibakeFreeVerified:true`
- Added manifest issue ids:
  - `style-proof-manifest-paste-editor-tab-not-verified`
  - `style-proof-manifest-paste-input-not-verified`
  - `style-proof-manifest-editor-body-not-mutated`
  - `style-proof-manifest-paste-mojibake-not-ruled-out`
  - `style-proof-manifest-paste-proof-not-bound`

Regression coverage:
- Same-tab, focused body editor with OS key events but no paste/input and no body DOM mutation stays
  invalid for `pc-editor-paste-event`.
- Wrong-tab or mojibake-damaged rich body readback stays invalid for `pc-editor-paste-event`.
- Required paste flags split across multiple artifacts stay invalid; all strong flags must be
  bound to the same `pc-paste` artifact.
- Existing strong Amber-style proof fixtures were updated to carry the new bound flags.
