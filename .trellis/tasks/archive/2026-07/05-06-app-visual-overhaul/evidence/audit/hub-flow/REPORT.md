## 1366×768 截图分析

### 默认状态 (1366-default.png)

**严重问题（阻断性）**

- ❌ **第一屏严重溢出**：右侧"新建作品"卡的"模板创建/导入文档"双按钮被视口下边缘截断，仅露出黑色按钮上半部分（约 24px 可见，按钮自身约 44px 高）。3px 红色 hairline 也被截断。这是 1366 视口下第一屏失败的核心问题，违反"首屏内完整显示"目标。
- ❌ **章节点 SectionDots 与累计指标卡的"字数/完成率"行重叠**：右侧第一个 active 红点 (1293,323) 落在新建作品卡右缘外部，但 dot 的红色与卡片白底之间没有缓冲，视觉上两者粘连；其余 3 个灰点 (1295,363/403/443) 与"字数 3 / 完成率 0%"行水平对齐处距卡片右边只有约 18px，呼吸感不足。

**色板与设计语言**

- ✅ Hero 卡白底纯净 (#FFFFFF)，左侧 3px 红条 (#D32F2F) 清晰可见。
- ✅ "创作流" Serif 36px 标题端正，副标题"本周产出 1 篇" 13px 灰。
- ✅ 累计指标卡 64px Serif "1" + tabular-nums，但 **eyebrow"累计"颜色明显偏红 (#D32F2F)**——与 Hero 卡的红条争夺视觉焦点，违反"红色 1% accent"原则。同样问题出现在每日灵感卡的"-- 莫言"上方 source-tag。
- ⚠ "新建作品"卡 22px Serif 标题 OK，但"开始" eyebrow 也是红色 (#D32F2F)，**3 个红色 eyebrow（创作流副标题不算）出现在同一第一屏视野**：累计、开始、每日灵感（"本地名言"标签）——红色已经超过 5% 的视觉份额。
- ⚠ "新建作品"卡的"1 草稿 / 1 连续创作天" 数字使用了 Serif 但**重量过轻**，与 64px"1"的视觉重量不匹配，弱化了"累计"卡的纵向呼吸。

**柱状图**

- ✅ 默认 bar 灰色接近 #ECEFF1，active 周三红色 #D32F2F 单独出现，符合规范。
- ✅ bar 间距视觉上接近 14px，但**柱高过夸张**：active 柱顶部 (270,180) 距 Hero 副标题 (105,160) 仅 20px 间隙，柱状区与标题区视觉粘连，破坏 8px 栅格。建议减少柱高 30%+ 给标题留呼吸。

**继续创作按钮 hero-continue-btn**

- ✅ 圆胶囊 999px 形态正确。
- ⚠ 默认态 kicker"继续创作"已经是红色 #D32F2F——这意味着 hover 转红的反馈消失了（参见 1366-continue-hover）。**默认就红，hover 不变化** = 视觉一致性瑕疵：要么默认改为灰色 (#666) 保留 hover 红的反馈，要么默认红，hover 加深加粗。

**每日灵感卡**

- ⚠ 卡左侧 3px 红条与每日灵感图标 (★) 上方"每日灵感" eyebrow + 右上角设置图标（齿轮）+ 引文红色边框 = 同一卡片**至少 3 处红色信号**，视觉密度过高。
- ⚠ 引文"本地名言"标签在 1366 截图中被**视口下边缘裁切**（仅露出标签上沿 2px），证明每日灵感卡也未在第一屏内完整显示。

**8px 栅格**

- ⚠ Hero 卡内"创作流"标题左 padding ≈ 60px，副标题"本周产出 1 篇"左 padding 也是 60px——但与左侧 3px 红条之间是约 57px，不是 8 倍数。
- ⚠ 累计指标卡上下 padding 估计 24px / 28px 不等高，"累计创作" paragraph 与下方"字数/完成率"行之间约 64px 空白，过于松散，视觉上像断开成两个卡。

### 头像弹层 (1366-avatar-popover.png)

- ❌ **头像 popover 严重遮挡新建作品卡**：popover (1100,82) 自右上角向下展开 220px×260px，覆盖了"开始/新建作品"标题 + 副文案 + 黑色"模板创建"按钮。用户在打开账户菜单时**看不到自己想去的"新建作品"操作**，破坏第一屏的核心创作引导。
- ⚠ popover 内"退出"项颜色为红色 #D32F2F，但与 Hero 红条/累计 eyebrow/继续创作 kicker 共占第一屏 4 处红，加重红色超载。
- ⚠ popover 边框与 Hub 整体白底卡片缺乏区分（同色 + 微 shadow），视觉层级混淆。
- ✅ "本地账户/账户管理/设置/切换账户/退出" 5 行项排布合理，行高约 36px，与 Hub 其他卡内容行高接近。

### 柱状图周三点击 (1366-bar-click.png)

- ✅ 弹窗中央居中 (476,287) 380×175，2026 年 5 月 6 日 + 周三·1篇 + 文章卡片，信息层级清晰。
- ⚠ 弹窗背景是**全屏 mask + blur 8-12px**，遮挡了下方所有 4 张右侧卡（累计/新建作品/最近编辑/每日灵感）。这种遮罩对一个简单"周三 1 篇详情"过于重，用户无法在弹窗显示时同时浏览右侧累计数据。建议改为**轻 dimmer 30% + 仅高亮当前 bar** 的轻量交互。
- ⚠ 弹窗"3 字 · 1 篇文章" 副标题使用 #D32F2F（屏幕中清晰可见），又是一处红。
- ⚠ 弹窗右上角关闭 X (855,322) 的尺寸 16×16 偏小，hit area 不足 32px。

### 继续创作 hover (1366-continue-hover.png)

- ✅ Hover 后按钮 border 转红 #D32F2F，符合规范。
- ✅ kicker"继续创作"在 hover 态依然为红——但因默认就红，所以观察不到颜色变化（仅有 border 从淡灰变深红）。
- ⚠ translateY(-1px) 视觉差不明显（截图中按钮顶部从 134→130 ≈ 4px 上移），说明实际位移可能比 -1px 更大，或截图时机正好落在 transform 末尾。
- ⚠ Hover 后整个按钮**外发光/阴影增强不足**，与 default 几乎只有 border 颜色差异，反馈不够清晰。

## 严重 BUG（阻断性）

1. **1366×768 第一屏严重溢出**：新建作品卡 CTA 按钮被裁，Hero 红条底部缺失，违反 1366 必须完整显示的目标。**必须修复**：缩短 Hero 卡柱状图高度 / 缩小累计指标卡 padding / 让 Hub 第一屏整体高度 ≤ 720px（去除 48px 浏览器 chrome）。
2. **头像弹层在所有视口下都遮挡新建作品卡 CTA**：用户打开账户菜单时无法看见"新建作品"。需要重新定位 popover（如 right-aligned 但向下偏移，或增加 z-index 层级 + 半透明 mask 而非完全遮挡）。
3. **柱状图点击弹窗 mask 过度**：全屏 blur 隐藏了所有右侧内容，对单 bar 详情过重。改为轻 dimmer + bar 高亮即可。
4. **红色 1% accent 原则被严重违反**：第一屏单视野出现 5-6 处独立红色信号（Hero 红条 / 累计红 eyebrow / 开始红 eyebrow / 继续创作红 kicker / 每日灵感红条 + 图标 / SectionDots active 红点 / 头像弹层"退出"红 / 弹窗副标题红）。设计语言要求红色仅作为最强 accent，每屏 ≤2 处，目前已超载 3 倍。

## 改进建议（设计师视角）

### 红色 accent 重新分配（核心）

- **保留**：Hero 卡左侧 3px 红条（这是 InkForge 品牌锚点）+ 章节点 active 红点（导航必需）。
- **降级到深灰**：累计 eyebrow / 开始 eyebrow / 字数分布等数据卡 eyebrow → #455A64 或 #607D8B 灰，配合 1.5px tracking 11px 仍然能形成视觉识别。
- **降级到黑**：继续创作 kicker"继续创作" → #263238 默认；hover 再转红，**让 hover 反馈"复活"**。
- **每日灵感卡**：去掉左侧红条 + 引文红边框，改为深灰 1px 边 + 红色仅出现在 ★ 图标。

### 第一屏内容布局（1366 优先）

- Hero 卡柱状图柱高从当前 ≈300px 降至 200-220px，给"创作流"标题留 40px 呼吸。
- 累计指标卡缩短 padding（24px→20px）+ 调整字数/完成率行靠近"累计创作" paragraph。
- 新建作品卡的 1/1 数字行去掉，统一并入按钮下方"1 草稿 · 1 连续创作天" 的小字注释。
- 整体目标：1366×768 视口下，6 张创作流卡全部进入第一屏（含"模板创建/导入文档"按钮 + 每日灵感引文）。

### 交互弹层

- **头像 popover**：使用 floating-ui / @vueuse/core 的 useFloating，placement="bottom-end" + offset 8px + flip + shift。让 popover 永远不遮挡同一行的功能区。
- **柱状图弹窗**：去除 backdrop blur，改为 4-6px 阴影下的居中卡 + 仅当前 bar 高亮（其他 bar 降低 50% 不透明度）。

### 8px 栅格修正

- Hero 卡内 padding：左 60px → 64px (8 的倍数)。
- 卡片之间垂直间距统一为 16px / 24px / 32px 三档，目前混用 12px / 18px / 22px。
- 累计指标卡的字数/完成率行距 paragraph 64px → 32px。

### 继续创作按钮

- Default：bg #FFFFFF / border 1px #ECEFF1 / kicker #455A64 / title 黑 #263238。
- Hover：border #D32F2F / kicker #D32F2F / translateY(-1px) / shadow 0 2px 8px rgba(211,47,47,0.12)。
- 当前默认就是 hover 状态，需调整 default 配色。

### 章节点 SectionDots

- 当前位置 right: ≈25-30px 在 1920 下贴边过紧，建议固定 right: 32px 并增加 dot 之间间距至 16px (当前 ≈40px，间距过大)。
- active 红点直径 10px，inactive 灰点 8px——可保留这个 size 差异，但 active 红 #D32F2F 在视觉上过艳，建议换为深红 #B71C1C 或加 ring 视觉。
