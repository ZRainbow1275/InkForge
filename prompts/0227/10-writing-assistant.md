# 10 - 写作辅助功能 Spec

## 目标
提供丰富的写作辅助工具，提升创作体验和内容质量。

## 1. 状态栏统计

### 1.1 底部状态栏
位于编辑器底部，显示：
- 字数（中文字符 + 英文单词）
- 段落数
- 预计阅读时间（按 400 字/分钟计算）
- 图片数量
- 当前编辑位置（行:列）

### 1.2 详细统计弹窗
点击状态栏展开详细信息：
- 中文字数
- 英文单词数
- 标点符号数
- 句子数
- 段落数
- 标题数（H2/H3/H4）
- 链接数
- 图片数
- 预计阅读时间

## 2. 可读性评分

### 2.1 评分维度
| 维度 | 算法 | 权重 |
|------|------|------|
| 句子长度 | 平均每句字数 <40 为优 | 25% |
| 段落密度 | 平均每段字数 <200 为优 | 25% |
| 标题频率 | 每 300-500 字一个标题 | 20% |
| 引用密度 | 适量引用（1-3 处/千字） | 15% |
| 列表使用 | 适量列表辅助结构化 | 15% |

### 2.2 评分等级
- A：优秀（85-100）
- B：良好（70-84）
- C：一般（55-69）
- D：需改进（40-54）
- F：差（<40）

### 2.3 改进建议
根据评分自动生成改进建议：
- "段落偏长，建议分段"
- "缺少标题结构，建议添加二级标题"
- "句子平均长度过长，建议拆分"

## 3. 智能标点转换

### 3.1 自动转换规则
| 输入 | 输出 | 说明 |
|------|------|------|
| `--` | `——` | 破折号 |
| `...` | `……` | 省略号 |
| `"text"` | `「text」` | 直角引号（可配置） |
| `'text'` | `『text』` | 直角引号 |

### 3.2 中英文混排优化
- 中英文之间自动插入半角空格
- 中文与数字之间自动插入半角空格
- 全角标点后不加空格

## 4. 段落呼吸提醒

当连续输入超过 500 字未分段时：
- 编辑器侧边出现微弱的橙色渐变提示
- 提示文字："段落较长，建议适当分段"
- 点击可快速在当前位置插入段落分割

## 5. 打字机模式

### 5.1 实现方案
```typescript
// TipTap 扩展
const TypewriterMode = Extension.create({
  name: 'typewriterMode',

  addProseMirrorPlugins() {
    return [
      new Plugin({
        view: (editorView) => ({
          update: (view, prevState) => {
            if (typewriterEnabled.value) {
              // 将当前光标位置滚动到编辑器垂直中心
              const coords = view.coordsAtPos(view.state.selection.head)
              const editorRect = view.dom.getBoundingClientRect()
              const offset = coords.top - editorRect.top - editorRect.height / 2
              view.dom.scrollTop += offset
            }
          }
        })
      })
    ]
  }
})
```

## 6. 文章模板

### 6.1 内置模板
| 模板 | 结构 |
|------|------|
| 教程类 | 引言 → 步骤 1-N → 总结 |
| 评测类 | 产品介绍 → 优点 → 缺点 → 总结 |
| 日记类 | 日期 → 今日记录 → 感想 |
| 技术博客 | 背景 → 方案 → 实现 → 测试 → 总结 |
| 新闻稿 | 标题 → 导语 → 主体 → 背景 → 引用 |
| 读书笔记 | 书名信息 → 核心观点 → 金句摘录 → 个人感悟 |

### 6.2 模板插入
- 从首页"开始新项目"选择模板
- 从编辑器斜杠命令 `/template` 插入
- 模板预览后确认插入

## 7. 链接检测

### 7.1 死链检测
- 导出前自动检测文章中的所有链接
- 发送 HEAD 请求验证链接有效性
- 标记 404 等无效链接
- 给出修复建议

### 7.2 平台兼容性检查
- 微信模式：提醒非 mp.weixin.qq.com 链接将被转为脚注
- 小红书模式：提醒所有链接将被移除
- 知乎模式：提醒外链会经过知乎跳转页
