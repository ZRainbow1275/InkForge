## 详细决策

### EX-01 | 快速笔记 / Scratch Pad
> 类似 Apple Notes 或 Obsidian Daily Notes 的快速记录能力

**决策**: ✅ **v2.1 实现** —— 全局快捷键打开轻量输入框，内容自动归入草稿箱

---

### EX-02 | 文档内锚点与内链
> 类似 Obsidian 的 `[[文章名]]` 内部链接能力

**决策**: ✅ **v2.1 实现** —— 支持文档间链接，点击跳转

---

### EX-03 | 命令面板（Command Palette）
> 类似 VS Code 的 Ctrl+Shift+P 全局命令搜索

**决策**: ✅ **v2.1 实现** —— 统一搜索所有可执行命令

---

### EX-04 | 最近打开文档列表
> 类似 VS Code 的 Ctrl+R 或 JetBrains 的 Recent Files

**决策**: ✅ **已有** —— card-recent 已覆盖，无需重复实现

---

### EX-05 | 文档对比 / Diff 视图
> 两个版本或两篇文档的差异对比

**决策**: ✅ **v2.1 实现** —— 版本历史中的 diff 视图

---

### EX-06 | 字数统计独立窗口 / 报告
> 类似 Ulysses 的详细统计面板

**决策**: ✅ **v2.1 实现** —— 可展开的详细统计面板（段落数、句子数、词频等）

---

### EX-07 | 自定义 CSS 注入
> 允许用户为编辑器或导出注入自定义 CSS

**决策**: ✅ **v2.1 实现** —— Settings > Advanced 中提供 CSS 编辑器
**注**: 用户**未选** "安全风险太高，不做"，确认开放此能力

---

### EX-08 | 文档模板变量 / 片段
> 类似 TextExpander 或 VS Code Snippets 的文本片段系统

**决策**: ✅ **v2.1 实现** —— 可定义常用文本片段，通过 `/` 或快捷键插入

---

### EX-09 | 深度链接（Deep Link）
> `inkforge://article/{id}` 格式的 URL scheme，允许从外部直接打开指定文档

**决策**: ⬜ **v2.2 考虑** —— v2.1 不实现 Tauri URL scheme 注册

---

### EX-10 | 正文内搜索引用 / 来源标注
> 写作时引用外部来源，并保持引用链可追溯

**决策**: ✅ **v2.1 实现** —— 支持引用块关联外部来源 URL

---

## 附录小结

- **v2.1 纳入实现**: 8 项（EX-01/02/03/05/06/07/08/10）
- **已有覆盖**: 1 项（EX-04）
- **延后到 v2.2**: 1 项（EX-09）
- **完全不做**: 0 项

**关键观察**: 用户对竞品功能的接纳度很高，仅深度链接（系统级 URL scheme）延后。**自定义 CSS 注入** 在用户已警惕"安全风险"选项的前提下仍勾选 v2.1 实现，需在实施时设计沙箱与白名单。
