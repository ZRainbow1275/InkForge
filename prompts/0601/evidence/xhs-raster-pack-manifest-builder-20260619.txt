XHS Raster Pack Manifest Builder - 2026-06-19

Scope:
- Local multi-page Xiaohongshu raster artifact manifest construction.
- Covers carousel/page-pack metadata before native export preflight.
- No account upload, no platform preview, no public URL acceptance, no publish.

Implemented:
- createXhsImageArtifactManifestFromRasterArtifacts(options)

Behavior:
- Reuses createXhsImageArtifactManifestFromRaster() for each real raster artifact.
- Sorts pages deterministically by page number.
- Defaults cover to page 1 unless an explicit cover/coverPage is supplied.
- Derives bodyReferences from pages whose referencedByBody is not false unless the caller supplies bodyReferences.
- Keeps validator authority in validateXhsImageArtifactManifest().
- Empty artifact packs throw immediately.
- Duplicate pages, gapped pages, invalid body references, duplicate cover, missing files, bad ratio/format/bytes, and crop overflow remain validator failures, not fabricated readiness.

Regression coverage:
- Unit tests cover a validator-clean two-page carousel pack.
- Unit tests cover explicit mismatched bodyReferences and duplicate page numbers being caught by validateXhsImageArtifactManifest().
- Native export tests cover passing the multi-page manifest through convertToNativeFormat(..., 'xiaohongshu') without manifest quality issues.
