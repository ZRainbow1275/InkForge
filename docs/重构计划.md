# InkForge 重构计划

> **版本**：v3.0

---

## 一、重构背景

### 1.1 现状分析

InkForge 项目已有初步实现，但存在以下问题需要重构解决：

| 问题类别 | 现状 | 影响 |
|---------|------|------|
| **架构分散** | 多个视图入口，代码重复 | 维护成本高 |
| **功能不完整** | 编辑器交互待增强 | 用户体验差 |
| **平台单一** | 仅支持微信公众号 | 适用范围窄 |
| **文档缺失** | 无规范开发文档 | 协作困难 |

### 1.2 重构目标

1. **统一架构**：以 Ethereal Studio (Gen 5.0) 为核心，整合所有视图
2. **完善功能**：补齐 P0 核心功能，增强编辑器交互
3. **扩展平台**：支持小红书、知乎等平台导出
4. **规范开发**：建立完整的开发文档和规范

### 1.3 重构执行进度

| 阶段 | 内容 | 状态 | 备注 |
|------|------|------|------|
| **Phase 1** | TS 错误修复 | ✅ 全部完成 | 22 个错误已修复，vue-tsc 零错误 |
| **Phase 2** | 导出渲染增强 | ✅ 全部完成 | 6 个 Sprint 全部交付 |
| **Phase 3** | 文档同步 | 🔄 进行中 | 同步文档至最新架构 |

#### Phase 2 Sprint 明细

| Sprint | 任务 | 状态 |
|--------|------|------|
| Sprint 2.1 | 管线架构 — 导出服务拆分为模块化架构 | ✅ |
| Sprint 2.2 | 微信渲染增强 — 8 步管线、12 种预设、7 种代码主题 | ✅ |
| Sprint 2.3 | 小红书纯文本引擎 — 5 种预设、emoji 装饰、外链剥离 | ✅ |
| Sprint 2.4 | 知乎 Markdown 引擎 — 3 种预设、学术引用、Mac 代码块 | ✅ |
| Sprint 2.5 | 主题系统 — 20 个预设（微信 12 + 小红书 5 + 知乎 3） | ✅ |
| Sprint 2.6 | 多平台 UI + 质量检测 — ExportModal 多平台、质量检测器 | ✅ |
