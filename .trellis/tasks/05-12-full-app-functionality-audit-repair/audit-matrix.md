# Full App Functionality Audit Matrix

Status values:

- `pending`: inventory row created, not yet verified.
- `pass`: verified with linked evidence and no repair required.
- `fail`: verified failure, not yet repaired.
- `fixed`: repaired and re-verified.
- `blocked`: cannot pass because a required runtime/tool/provider is unavailable; must include exact evidence.

No row may be marked `pass` from static reading alone when user-visible behavior is involved.
